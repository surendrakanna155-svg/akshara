
AKSHARA ERP
MASTER SOFTWARE REQUIREMENTS SPECIFICATION (SRS)
VERSION 1.0 - PART 13
DETAILED API CONTRACTS

====================================================
1. API STANDARDS
====================================================

Base URL:
/api/v1

Format:
JSON

Authentication:
JWT Bearer Token

Response Format:

{
  "success": true,
  "message": "Operation successful",
  "data": {}
}

====================================================
2. LOGIN API
====================================================

POST /auth/login

Request:

{
  "email":"user@example.com",
  "password":"******"
}

Response:

{
  "success":true,
  "token":"jwt_token",
  "role":"teacher"
}

====================================================
3. STUDENT CREATE API
====================================================

POST /students

Request:

{
  "school_id":"uuid",
  "admission_number":"A001",
  "first_name":"Ravi",
  "last_name":"Kumar"
}

Response:

{
  "success":true,
  "student_id":"uuid"
}
