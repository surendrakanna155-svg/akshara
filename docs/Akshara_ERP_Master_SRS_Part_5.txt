SECURITY, PRIVACY, MULTI-TENANT SAAS & COMPLIANCE

====================================================
1. SECURITY OVERVIEW
====================================================

Objective:
Provide enterprise-grade security for schools, parents,
students, teachers, and management.

Core Principles:

- Security by Design
- Privacy by Default
- Least Privilege Access
- Auditability
- Data Ownership

====================================================
2. DATA OWNERSHIP POLICY
====================================================

School owns all data.

Akshara ERP acts only as a technology provider.

Data Ownership Includes:

- Student Data
- Parent Data
- Teacher Data
- Financial Data
- Hostel Data
- Transport Data
- Academic Data

Akshara ERP does not claim ownership.

====================================================
3. DATA PRIVACY POLICY
====================================================

Akshara Employees Cannot Access:

- Parent Phone Numbers
- Student Personal Data
- Staff Personal Data
- Salary Records
- Financial Records
- Medical Records
- Private Messages

Only platform-level metrics are visible.

Examples:

Visible:
- Total Schools
- Active Users
- Storage Usage

Not Visible:
- Student Names
- Parent Contacts
- Fee Records
- Salary Information

====================================================
4. MULTI TENANT ARCHITECTURE
====================================================

Each record contains:

school_id

Benefits:

- School Isolation
- Scalability
- Cost Efficiency

Security:

- Row Level Security
- Tenant Isolation
- API Protection

School A can never access School B data.
