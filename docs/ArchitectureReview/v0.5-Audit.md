# Architecture Review — v0.5 Audit

**Date:** June 2026  
**Scope:** Full repository scan (stabilization phase)  
**Method:** Static analysis, grep inventory, test coverage, manual route review  
**Constraint:** No functionality changes in this audit

---

## Executive Summary

The codebase is well-structured for a mock-data MVP with consistent Riverpod + GoRouter patterns. Primary technical debt is **triplicated ERP module scaffolding** (Admissions, Finance, SIS) and **76.6% line coverage** (below 80% target). No P0 security or routing blockers found.

---

## P0 — Address Before Management MVP

| ID | Finding | Impact | Recommendation |
|----|---------|--------|----------------|
| P0-01 | **v0.3–v0.5 ERP modules uncommitted** | Tag/release drift; CI runs stale code on `main` | Commit Admissions, Finance, SIS, tests, docs in single release commit |
| P0-02 | **No API / repository layer** | All providers are in-memory mocks | Introduce `Repository` interfaces before Management MVP data sharing |
| P0-03 | **Staff role bypasses persona RBAC** | `adminPersonaProvider` always returns `superAdmin` | Wire persona to auth claims before multi-role rollout |
| P0-04 | **No CI until v0.5.1** | Regressions undetected | ✅ Resolved: `.github/workflows/flutter_ci.yml` added |

## P1 — High Priority Improvements

| ID | Finding | Impact | Recommendation |
|----|---------|--------|----------------|
| P1-01 | **Triplicated module scaffolds** | 3× `*SubNav`, `*ModuleScaffold`, `*ResponsiveGrid`, `*KpiRow` | Extract shared `ErpModuleScaffold` in `lib/shared/module/` |
| P1-02 | **Triplicated handoff/conversion queues** | Finance `FinanceHandoffQueue`, SIS `SisEnrollmentQueue` | Shared `ErpQueueTable` with column config |
| P1-03 | **Coverage 76.6%** (target 80%) | Gap in error/empty branches, placeholder actions | Add provider tests for override paths; smoke empty/error flags |
| P1-04 | **Tablet layout overflow** | `AksharaInsightCard` overflows at 834px in Student/Teacher dashboards | Wrap action row with `Flexible` or `Wrap` (UI fix) |
| P1-05 | **Hardcoded strings** | No i18n; labels scattered across 53 screens | Introduce `AppStrings` or `flutter_gen` l10n before multi-language |
| P1-06 | **Integration state in `StateProvider` maps** | Handoff/conversion overrides are ephemeral | Persist via shared event store or API callbacks |
| P1-07 | **Golden tests macOS-only** | Linux CI skips 9 tests | Acceptable; document in CoverageGuide ✅ |
