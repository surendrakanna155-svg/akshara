## DTO / Mapper / Remote Gaps

| Gap | Severity |
|-----|----------|
| Only dashboard DTO per module | P1 — need DTOs per endpoint |
| Mappers throw `UnimplementedError` | Expected (scaffolding) |
| Remote DS only `fetchDashboard()` scaffolded | P1 — need methods matching interface |
| No JSON serialization code gen | P2 — `json_serializable` not added |
| No API response envelope parsing | P1 — TechnicalArchitecture defines `{success, data, meta}` |
| No auth interceptor | P1 — JWT not injected dynamically |
| No tenant interceptor | P1 — `X-School-Id` hardcoded at Dio creation |
| No retry/error interceptors | P2 — per TechnicalArchitecture spec |
| Sync interface vs async HTTP | **P0** — fundamental mismatch |

## Findings

### P0

| ID | Finding |
|----|---------|
| API-P0-01 | **Sync repository interfaces** — cannot call HTTP without refactor to `Future<T>` or internal sync cache |
| API-P0-02 | **Api repositories throw on any call** — enabling `useApiRepositoriesProvider` breaks all screens immediately |

### P1

| ID | Finding |
|----|---------|
| API-P1-01 | Complete remote datasource methods for all interface methods |
| API-P1-02 | Implement mappers for all DTOs |
| API-P1-03 | Add auth + tenant Dio interceptors from session |
| API-P1-04 | Parse standard API envelope |
| API-P1-05 | Feature-flag per module (not global `useApiRepositoriesProvider`) |
| API-P1-06 | Integration tests against mock HTTP server |

### P2

| ID | Finding |
|----|---------|
| API-P2-01 | `json_serializable` + build_runner |
| API-P2-02 | Local datasource (Drift) for cache-first reads |
| API-P2-03 | Remove `// ignore_for_file: unused_field` when wiring remote calls |

---

## Migration Path (Recommended)

1. **Phase A** — Add `Async*` parallel providers (don't break sync mocks).
2. **Phase B** — Implement `ApiFinanceRepository.getDashboard()` end-to-end as pilot.
3. **Phase C** — Feature flag per module: `useApiFinanceProvider`.
4. **Phase D** — Migrate screens to `AsyncValue` pattern.
5. **Phase E** — Remove sync interfaces when all modules migrated.
