## Findings

### P0 — Must fix before production

| ID | Finding | Risk |
|----|---------|------|
| RBAC-P0-01 | **All `UserRole.staff` sessions are superAdmin** | Any staff user accesses Finance, Control Center, all modules |
| RBAC-P0-02 | **No route guard on `/control-center/*`** | Platform admin screens reachable by any staff via URL |
| RBAC-P0-03 | **Client-only RBAC** | Bypass via API/deep link once backend exists; no RLS enforcement |
| RBAC-P0-04 | **No tenant (`school_id`) scoping** | Multi-school data leakage risk at API layer |

### P1 — Should fix before API rollout

| ID | Finding | Risk |
|----|---------|------|
| RBAC-P1-01 | **Persona nav filtering not wired to auth claims** | RBAC spec exists in `kAllAdminNavDestinations` but unused |
| RBAC-P1-02 | **No per-module route guards** | Finance Admin can navigate to `/hr/payroll` via URL |
| RBAC-P1-03 | **Staff home = Teacher dashboard** | ERP staff land on mobile teacher shell, not admin hub |
| RBAC-P1-04 | **No RBAC tests** | Zero automated persona/route guard coverage |
| RBAC-P1-05 | **Teacher role accesses ERP** | `UserRole.staff` required for ERP; teachers without staff flag blocked |

### P2 — Recommended refinements

| ID | Finding |
|----|---------|
| RBAC-P2-01 | Add `platformAdmin` distinct from `schoolAdmin` |
| RBAC-P2-02 | Wire Director.md routes separately from Management |
| RBAC-P2-03 | Read-only (`👁`) vs write (`✅`) action guards per screen |
| RBAC-P2-04 | Hide nav items vs block routes — align both layers |

## Production-Ready RBAC Recommendations

1. **Auth claims** — JWT with `roles[]`, `personas[]`, `school_id`, `allowed_modules[]`.
2. **Wire `adminPersonaProvider`** — Map from auth claims, not hardcoded `superAdmin`.
3. **Route guards** — Add `_canAccessAdminModule(location, persona)` in `_authRedirect`:
   - Control Center → `superAdmin` or `platformAdmin` only
   - Finance → `financeAdmin | superAdmin | management`
   - etc. (mirror `allowedPersonas` in nav destinations)
4. **Server RLS** — Supabase policies enforce tenant + role regardless of client bypass.
5. **RBAC test suite** — Matrix test: each persona × module routes → expect allow/deny.
6. **Staff home route** — `homeRouteForRole(UserRole.staff)` → `RouteNames.admin` or last-visited ERP module.

**RBAC maturity score: 3 / 10** (structure defined; enforcement absent)
