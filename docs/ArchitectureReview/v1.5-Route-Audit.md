## Naming Convention Review

| Pattern | Compliance | Example |
|---------|------------|---------|
| Module prefix | ✅ | `/finance/dashboard` |
| kebab-case segments | ✅ | `/fee-structures`, `/white-label` |
| `RouteNames` constants | ✅ | All paths centralized |
| Module route lists | ✅ | `financeRoutes`, `hrModuleRoutes`, etc. |
| Named GoRoutes | ✅ | `name: 'financeDashboard'` |
| Dynamic helpers | ✅ | `sisStudentDetail(id)`, `hrEmployeeDetail(id)` |

### Naming inconsistency

| Issue | Detail |
|-------|--------|
| Control Center path | `/control-center` (kebab) vs module enum `controlCenter` (camel) — acceptable |
| Alumni profile | `/alumni/profile/:alumniId` — `alumniProfile` constant is `/alumni/profile` prefix only |

## Findings

### P0

| ID | Finding |
|----|---------|
| ROUTE-P0-01 | **No RBAC on deep links** — any staff can deep-link to any ERP path |
| ROUTE-P0-02 | **`RouteInventory.md` inaccurate** — ops/docs risk for production routing |

### P1

| ID | Finding |
|----|---------|
| ROUTE-P1-01 | **`app_router.dart` monolith** (~1,450 lines) — merge conflict risk |
| ROUTE-P1-02 | **`debugLogDiagnostics: true`** — should gate behind `kDebugMode` |
| ROUTE-P1-03 | **Router smoke test incomplete** — does not cover all 130 routes (samples per module) |
| ROUTE-P1-04 | **Staff cannot deep-link to teacher from ERP** — by design but `homeRouteForRole(staff)` = teacher |

### P2

| ID | Finding |
|----|---------|
| ROUTE-P2-01 | Split `app_router.dart` into `parent_routes.dart`, `admin_routes.dart`, etc. |
| ROUTE-P2-02 | Add `RouteNames.allRoutes` master list for smoke test generation |
| ROUTE-P2-03 | Web `PathUrlStrategy` for clean ERP URLs |
