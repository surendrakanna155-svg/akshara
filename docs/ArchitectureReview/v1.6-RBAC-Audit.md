## RBAC Service

Single check path:

```
authProvider → userPermissionsProvider → rbacServiceProvider → hasPermission()
```

Convenience providers: `canViewFinanceProvider`, `canManageAdmissionsProvider`, `currentPermissionsProvider`, etc.

## Navigation Filtering

`adminNavDestinationsProvider` filters `kAllAdminNavDestinations` by `requiredPermission`. Inaccessible modules are **not rendered** in `AdminNavigationRail`.

## Resolved v1.5 Gaps

| v1.5 Gap | v1.6 Resolution |
|----------|-----------------|
| `adminPersonaProvider` always `superAdmin` | Replaced with permission-driven nav |
| No route-level RBAC | `ErpRouteGuard` in `AdminShell` |
| Control Center open to all staff | SuperAdmin-only guard + matrix |
| 4 `UserRole` values only | 13 `ErpRole` values via `AuthClaims` |
