## Token model

### `AuthTokens` (`auth_token_models.dart`)

| Field | Purpose |
|-------|---------|
| `accessToken` | JWT bearer for API calls |
| `refreshToken` | Long-lived refresh credential |
| `expiresAt` | Access token expiry (`DateTime`) |

Helpers: `isExpired`, `isExpiringSoon` (5-minute window), `AuthTokens.demo()` for tests.

### `TokenStorage` (`token_storage.dart`)

- Persists to SharedPreferences key `auth_tokens_v1`
- JSON serialization with ISO-8601 expiry
- Cleared on `logout()`

### Riverpod providers (`auth_token_provider.dart`)

| Provider | Role |
|----------|------|
| `tokenStorageProvider` | Storage singleton |
| `authTokensProvider` | Current tokens (async) |
| `tokenRefreshCallbackProvider` | Injectable refresh function |
| `onTokensRefreshedProvider` | Persist callback after refresh |

## AuthClaims extensions

```dart
final DateTime? accessTokenExpiresAt;
bool get isTokenExpired;
bool get isTokenExpiringSoon;
```

Synced from `AuthTokens.expiresAt` on:

- `verifyOtp()` → `_issueDemoTokens()`
- `resolveSession()` → reads stored tokens

Session storage (`auth_session_v2`) unchanged for claims; tokens stored separately.

## AuthInterceptor integration

| Flow | Behavior |
|------|----------|
| Request with valid token | Attaches `Bearer` header |
| Request with expired token + refresh callback | Awaits refresh, retries with new token |
| 401 response + refresh callback | Single refresh attempt, replays request |
| No token + `allowAnonymous: false` | Rejects before network |
| No token + `allowAnonymous: true` | Proceeds without header |

## AuthProvider changes

| Method | Token behavior |
|--------|----------------|
| `verifyOtp` | Issues demo tokens, persists, syncs expiry to claims |
| `signInStaff` | Issues demo tokens for staff sessions |
| `resolveSession` | Restores tokens; updates `accessTokenExpiresAt` on claims |
| `logout` | Clears session **and** token storage |

## Security notes

- Demo tokens are predictable — acceptable for MVP, **not** for production
- Tokens in SharedPreferences are unencrypted
- Refresh callback defaults to `null` — safe no-op until wired

## Recommendation (v1.9)
