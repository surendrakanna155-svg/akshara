# v12.7–v13.2 — Phase 10 Architecture Review

**Date:** June 2026  
**Scope:** Final Akshara School platform (Phase 10)  
**Score:** 93 / 100 (school ERP readiness)

## Strengths

- Syllabus automation reuses subject templates with chapter/topic hierarchy and academic-year cloning
- Academic progress separates teacher vs principal dashboards with pending-alert foundation
- Provider management is super-admin gated; credentials stored in vault without client key display
- Parent experience delivers structured summaries (attendance, performance, homework, exam readiness) — no open AI chat
- Timetable intelligence adds room/lab allocation, exam timetable generation, and conflict scoring

## Gaps

| Gap | Severity | Owner | Target |
|-----|----------|-------|--------|
| Production vault key management (HSM/KMS) | Medium | Backend | Pre-production |
| Live MSG91/Gupshup webhook delivery confirmation | Medium | Backend | v13.3 |
| Parent activation analytics dashboard | Low | Mobile | v13.3 |
| Exam timetable UI drag-and-drop editor | Low | ERP | Future |

## Recommendations

1. Run staging backfill for syllabus chapters after migration apply
2. Rotate vault secrets on a 90-day schedule once KMS is wired
3. Pilot first school with `SCHOOL_COMPLETION_API_ENABLED=true` and parent API enabled
