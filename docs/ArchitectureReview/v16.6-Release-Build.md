# Architecture Review — v16.6 Release Build

**Release:** v16.6-release-build

## Strengths

- Platform folders generated with consistent org (`com.akshara.erp`)
- Staging dart-defines centralized in `scripts/build_release.sh` — no secrets in repo
- Pilot builds use staging env (demo auth available as fallback)
- Device testing guide references existing demo seed phones

## Risks

| Risk | Mitigation |
|------|------------|
| Debug signing on Android release | Documented; acceptable for friend/pilot sideload only |
| Default Flutter icons | Documented pre-store TODO |
| iOS requires Xcode on signed Mac | Documented in Device-Testing-Guide |
| cmdline-tools / license warnings | Build may still succeed; verify on CI Mac |

## Security

- No API keys embedded; `API_BASE_URL` via dart-define at build time
- Production `disableDemoAuth` not enabled on pilot builds (intentional for QA fallback)
- INTERNET permission only; no excessive Android permissions
