# Architecture Review — v17.3 Authentication Hardening

**Release:** v17.3 (`v17.3-authentication-hardening`)  
**Score:** **95 / 100** (auth security weighted)

---

## Finding

Release builds (`APP_ENV=staging`) left mock mobile auth enabled. Any 6-digit OTP authenticated any 10-digit phone into a UI-selected demo persona.

## Fix architecture

```
LoginScreen
    ↓
AuthNotifier.sendOtp / verifyOtp
    ↓ (disableDemoAuth + AUTH_API_ENABLED)
AuthRepository → /auth/login + /auth/verify-otp
    ↓
UserRole from server scope/erpRole (not UI picker)
```

Testing mode (`ENABLE_DEMO_AUTH=true`) remains explicit opt-in with account chips and OTP `123456` only.

## Verdict

Pilot blocker resolved. Rebuild and reinstall release app required on devices.
