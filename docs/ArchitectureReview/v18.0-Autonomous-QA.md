---

## Auth navigation architecture (post-fix)

```
Login → sendOtp → AuthStatus.otpPending
OTP back → cancelOtpPending() → AuthStatus.unauthenticated → /login
Verify OK → authenticated → homeRouteForRole()
```

| Check | Before | After |
|-------|--------|-------|
| OTP app bar back | Trapped on OTP | Returns to login |
| Android system back | Trapped | Returns to login |
| Staff OTP back | Stale otpPending state | Reset + login |

## Recommendations

1. Merge QA-003 fix in demo school seed before teacher mobile pilot.
2. Keep `cancelOtpPending()` as the single escape hatch for OTP abandon — do not allow `/login` in redirect while otpPending without clearing state.
3. Extend first_run_navigation_test to staff OTP when staff API auth is enabled in widget tests.
