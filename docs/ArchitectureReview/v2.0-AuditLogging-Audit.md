# v2.0 Audit Logging Audit

**Date:** 2026-06-05  
**Scope:** Local audit event store and security event hooks

## Summary

Client-side audit logging foundation stores security events locally (max 200 entries) until server ingestion is available.

**Audit readiness: 70 / 100**

## Events tracked

| Event | Hook location |
|-------|---------------|
| `login` | `AuthNotifier.verifyOtp`, `signInStaff`, `completeStaffLogin` |
| `logout` | `AuthNotifier.logout` |
| `accessDenied` | `ErpRouteGuard` |
| `roleChange` | `AuthNotifier.setStaffErpRole` |
| `tenantChange` | Ready via `recordAuditEvent` (no UI hook yet) |

| File | Purpose |
