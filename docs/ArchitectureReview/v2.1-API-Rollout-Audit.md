## 7. Rollout Prerequisites (Each Module)

Checklist derived from Admissions + Finance:

- [ ] DTO files for all repository methods
- [ ] Full mapper (no hardcoded empty lists)
- [ ] Remote datasource (all GETs + query params)
- [ ] `ApiXxxRepository` wired (remove stubs)
- [ ] `xxx_async_state.dart` + ViewState providers
- [ ] All screens migrated to `*AsyncBody`
- [ ] Contract tests (mapper + fake Dio)
- [ ] Integration test (remote sweep + 1 provider)
- [ ] Release doc + architecture audit
- [ ] Feature flag default `false` until backend ready
