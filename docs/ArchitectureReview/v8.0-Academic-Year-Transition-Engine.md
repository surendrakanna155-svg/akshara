# Architecture Review — v8.0 Academic Year Transition Engine

**Score:** 88/100  
**Date:** June 2026

---

## Goals

Annual year rollover without manual SQL — preview → execute with class mappings and enrollment migration.

---

## Design

| Component | Path |
|-----------|------|
| Migration | `20260619000000_academic_year_transition_engine.sql` |
| Repository | `academic_transition_repository.ts` |
| Handlers | `academic_transition_handlers.ts` |
| Router | `academic_router.ts` (transition routes) |

**Flow:** Suggest mappings (auto +1 numeric classes) → preview job → execute promotions via `resolveAcademicPlacement` → optional set target current + archive source.

---

## RBAC

| Action | Permission |
|--------|------------|
| View job / suggestions | `viewSis` + school scope |
| Preview / execute | `manageSis` + school scope |

---

## Data model

`academic_year_transitions` — job status, `class_mapping` JSONB, preview/execution reports, counts.

No change to `sis_student_enrollments` schema — uses existing soft FK columns.

---

## Risks & gaps

| Item | Severity | Note |
|------|----------|------|
| No automatic rollback | Medium | Re-run preview; manual enrollment fix |
| Fee structure rollover | Low | Out of scope — finance separate milestone |
| Large schools (500+) | Medium | Batch execute future enhancement |
