## Phase A — root causes fixed

1. **Teacher KPI truncation** — `_FilledKpiTile` forced `dense` mode inside `Row` (unbounded height). Fixed dense heuristic; KPI strip uses fixed 112px height tiles with responsive short labels.
2. **Parent KPI overflow** — Same KPI fix + short labels on narrow widths.
3. **Intelligence Hub overflow** — Replaced fixed `tabHeight` `SizedBox` with `scrollableBody: false` + `Expanded` `TabBarView` inside `SizedBox.expand`.
4. **Finance chart legend clipping** — Increased `_cardChrome` to 136; legend text `maxLines: 2` + ellipsis.
