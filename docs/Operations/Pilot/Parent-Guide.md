# Parent Guide — Akshara Parent App

## Getting started

1. Install Akshara Parent app (or open web link from school)
2. Enter registered mobile number
3. Enter OTP from SMS/WhatsApp (staging shows OTP in demo response)
4. Select child if multiple children are linked

## Daily checks

- **Home** — Attendance status, homework due, fee reminders
- **Homework** — Assignments by subject with due dates
- **Notices** — School announcements

## Weekly checks

- **Attendance** — Calendar view and monthly KPIs
- **Timetable** — Child's weekly schedule
- **Fees** — Installment timeline and payment history

## Monthly checks

- **Academic report** — Performance, teacher guidance, exam readiness
- **Parent Experience Hub** — Structured insights and recommendations
- **Events** — School calendar

## Payments

1. Fees → select installment → Pay now
2. Choose payment method
3. Download receipt from Receipts tab

## Troubleshooting

| Issue | Action |
|-------|--------|
| Blank dashboard | Tap **Retry** on error banner |
| Wrong child shown | Open profile → switch child |
| Fees not visible | Contact school admin to assign fee structure |
| OTP not received | Confirm phone matches admission record |

## Privacy

Only guardians linked to your phone number can access your child's data. Never share your OTP.
