# Teacher Guide — NIKSHA OS Mobile & ERP

## Daily workflow

1. **Dashboard** — Today's periods, pending tasks, attendance summary
2. **Attendance** — Mark class attendance (draft → submit before cutoff)
3. **Homework** — Review submissions and send feedback
4. **Messages** — Reply to parent threads

## Weekly workflow

- Timetable — confirm next week's schedule
- Lesson logs — record topics covered per class
- Exam marks — enter marks for weekly tests
- Leave — submit requests via Teacher → Leave

## Monthly workflow

- Teacher Success Center — engagement and effectiveness scores
- Planning center — upcoming assessments and pending syllabus topics
- Parent meeting summaries — AI-assisted briefing before PTMs

## Mobile tips

- Use **retry** on error banners if network is slow
- Attendance works offline-first where configured; sync when connected
- Tablet layout centers content at 480px for comfortable marking

## Do not

- Record fee collections (accountant/admin task)
- Change student master data (registry admin task)
- Share OTP codes with parents — they receive their own login
