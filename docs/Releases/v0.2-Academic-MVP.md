## Technical Achievements

- **Shared design system** — 12 shared widgets in `lib/shared/widgets/`
- **Theme architecture** — Material 3 tokens via `AksharaAppTheme` and `theme_extensions.dart`
- **Auth** — Phone OTP flow with role selection (parent, teacher, student, staff)
- **Session persistence** — `SharedPreferences` via `auth_session_storage`
- **Notifications** — Shared notifications screen with mock provider
- **Riverpod** — 28 feature providers with mock data, loading/empty/error flags
- **GoRouter** — Shell routes for Parent, Teacher, Student apps; 36 registered routes
- **Responsive layouts** — Tablet breakpoint 768px, max content width 480px on mobile apps
- **Accessibility** — Semantics on app bars, KPI cards, lists, filters, and navigation

## Known Limitations

### API & data

- All providers use **mock data** — no REST/GraphQL integration
- No offline sync or caching layer
- Payment flow simulates Razorpay — no live gateway

### Auth & roles

- Staff role routes to teacher dashboard (placeholder)
- No biometric or refresh-token flow
- Language selection screen (P-02) not implemented

### Parent app gaps (per `docs/Parent.md`)

- Child selector modal (P-05) — chip only, no multi-child switch UI
- Homework detail (P-08), report cards (P-12), teacher messages (P-13/P-14)
- Bus tracking (P-15), certificates (P-16), transport screens
- Parent-specific notifications route (reuses shared screen)

### Teacher app gaps (per `docs/Teacher.md`)

- Teacher-specific notifications route
- Class teacher dashboard, AI copilot, profile routes (stub navigation)
- Staff check-in geo/face verification (dashboard only mock)

### Student app gaps (per `docs/Student.md`)

- Fifth "More" bottom-nav tab not implemented
- Join class, AI quiz, homework submission upload (stubs)
- Settings screen placeholder on profile
- Student-specific notifications route

### Platform & ops

- No `l10n` / internationalization
- No CI pipeline configuration in repo
- `debugLogDiagnostics` may still be enabled in router (dev only)
- Web/desktop ERP modules (Admissions, Finance, Management, etc.) not started
