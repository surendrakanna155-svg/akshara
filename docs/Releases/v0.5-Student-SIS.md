## Architecture Summary

| Layer | Technology |
|-------|------------|
| UI | Flutter 3.35+, Material 3, Akshara design tokens |
| State | Riverpod (`Provider`, `StateProvider`, `NotifierProvider`) |
| Routing | GoRouter nested `ShellRoute` per app role |
| Auth | `AuthState` + SharedPreferences persistence |
| Admin ERP | `AdminShell` → `AdminContentScaffold` → module scaffolds |
| Responsive | `AksharaBreakpoints` — desktop 1440, tablet 834, mobile 390 |
| Data | Mock providers with loading / empty / error flags |

### Module scaffolds

- `AdmissionsModuleScaffold` + `AdmissionsSubNav`
- `FinanceModuleScaffold` + `FinanceSubNav`
- `SisModuleScaffold` + `SisSubNav`

## Integration Summary

### Admissions → Finance (v0.4)

- `ApprovedStudentHandoff` consumed by Finance FN-01 / FN-04
- `feeHandoffStatusOverridesProvider` updates handoff on fee assignment

### Admissions → SIS (v0.5)

- `admissionsPendingEnrollmentsProvider` (AD-05 enrollment records)
- SIS-05 converts enrollment → SIS student profile
- `enrollmentConversionOverridesProvider` bidirectional status

### Finance → SIS (v0.5)

- `sisFeeAccountForAdmissionProvider` reads `financeStudentAccountsProvider`
- SIS-03 profile shows linked fee account summary

### Cross-app

- Parent PA-03 fees ↔ Finance receipt numbers (mock alignment)
- No live API or event bus yet

## Known Limitations

- **Mock data only** — no backend, persistence, or multi-tenant isolation
- **Staff role = superAdmin persona** — no fine-grained RBAC enforcement in UI
- **Placeholder ERP modules** — HR, Management, Transport, Hostel
- **Actions are UI-only** — export, promote, transfer, reconciliation, approve/reject
- **SIS conversion** — does not append converted students to registry mock list
- **Golden tests** — macOS only; tablet layout has known overflow in insight cards
- **Coverage** — 76.6% line coverage (target 80%+)
- **Uncommitted v0.5 work** — Admissions/Finance/SIS modules pending git commit at stabilization time
