# Transport MVP Release

**Version:** `v0.8-transport-mvp`  
**Date:** June 2026  
**Codename:** Transport MVP (TR-01 → TR-09)  
**Prior release:** Management MVP (v0.7)

---

## Overview

Transport MVP delivers nine admin screens for fleet operations: dashboard KPIs, route and vehicle management, driver roster, SIS-linked student allocation, pickup attendance, GPS tracking placeholder, reports, and module settings. Data flows through `TransportRepository` → `MockTransportRepository` with Riverpod providers — no inline mock data in screens.

| ID | Screen | Route |
|----|--------|-------|
| TR-01 | Dashboard | `/transport/dashboard` |
| TR-02 | Routes Management | `/transport/routes` |
| TR-03 | Vehicles | `/transport/vehicles` |
| TR-04 | Drivers | `/transport/drivers` |
| TR-05 | Student Allocation | `/transport/allocation` |
| TR-06 | Transport Attendance | `/transport/attendance` |
| TR-07 | GPS Tracking (placeholder) | `/transport/tracking` |
| TR-08 | Reports | `/transport/reports` |
| TR-09 | Settings | `/transport/settings` |

Bare `/transport` redirects to `/transport/dashboard`.

---

## Features Delivered

### TR-01 — Dashboard

- Six KPI tiles (active buses, on-time rate, delays, students picked, driver absent, fuel cost MTD)
- Live fleet assignment table with tracking status chips
- Occupancy metrics and route performance summary
- Active delay warning banner with link to tracking
- AI insight card with SIS allocation link

### TR-02 — Routes Management

- Route catalog with stops, distance, AM/PM departure, assigned bus, student count
- Status filters (All, Active, Draft, Inactive)
- Responsive DataTable (desktop) and cards (mobile)

### TR-03 — Vehicles

- Fleet registry with registration, capacity, GPS device, occupancy
- Derived KPI row (fleet size, active count, avg occupancy)
- Status filters (Active, Maintenance, Retired)

### TR-04 — Drivers

- Driver roster with license, phone, assigned bus, attendance, rating
- Status filters (Active, On leave, Inactive)

### TR-05 — Student Allocation

- SIS-linked allocations (`SIS-STU-*` IDs)
- Pickup/drop stops, route, bus assignment
- Navigation to SIS student detail and registry
- Integration insight card

### TR-06 — Transport Attendance

- AM pickup attendance with scheduled vs actual times
- Status filters (Picked, Waiting, Absent)
- Parent notification column

### TR-07 — GPS Tracking (placeholder)

- Map placeholder card (no live maps)
- Vehicle telemetry table (speed, ping, ETA, coordinates)
- Parent app integration link
- Architecture ready for Mapbox/Google Maps

### TR-08 — Reports

- Six-report catalog with download placeholders
- On-time performance trend chart
- Delay-by-route segment panel
- Fuel cost trend (Finance integration placeholder)

### TR-09 — Settings

- Shift configuration, GPS provider, parent app integration
- Finance transport fee placeholders
- SIS allocation/attendance sync placeholders

## Repository Architecture

### Repository contract

`TransportRepository` (`lib/core/repositories/interfaces/transport_repository.dart`):

| Method | Returns |
|--------|---------|
| `getDashboard()` | `TransportDashboardData` |
| `getRoutes()` | `List<TransportRoute>` |
| `getVehicles()` | `List<TransportVehicle>` |
| `getDrivers()` | `List<TransportDriver>` |
| `getAllocations()` | `List<StudentTransportAllocation>` |
| `getAttendanceRecords()` | `List<TransportAttendanceRecord>` |
| `getTrackingPlaceholder()` | `TransportTrackingPlaceholderData` |
| `getReports()` | `TransportReportsData` |
| `getSettings()` | `TransportSettingsData` |
| `getOccupancyMetrics()` | `OccupancyMetrics` |

### Repository implementation

`MockTransportRepository` (`lib/core/repositories/mock/mock_transport_repository.dart`) — integrated mock data aligned with SIS student IDs (Arjun Patel `SIS-STU-10421`, Emma Thomas, Ananya Reddy, Priya Sharma).

### Provider wiring

```
Screen → transport*Provider → transportRepositoryProvider → MockTransportRepository
```

Registered in `lib/core/repositories/repository_providers.dart` as `transportRepositoryProvider`.

Feature providers in `lib/features/transport/transport_providers.dart` with loading/error/empty `StateProvider` flags per screen.

| Module | Integration |

## Known Limitations

- GPS tracking is placeholder architecture only (TR-07) — no live maps
- No Mapbox/Google Maps SDK integration
- No API integration — all data via `MockTransportRepository`
- No real-time WebSocket/GPS feed
- Finance transport fee billing not implemented (settings placeholders only)
- Export/download buttons on reports are UI placeholders
