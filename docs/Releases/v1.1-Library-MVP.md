# Library MVP Release

**Version:** `v1.1-library-mvp`  
**Date:** June 2026  
**Codename:** Library MVP (LB-01 → LB-08)  
**Prior release:** Hostel MVP (v1.0)

---

## Overview

Library MVP delivers eight admin screens for school library operations: dashboard KPIs, book catalog, issue and return workflows, member registry, fines with Finance placeholders, digital resources with Student/Teacher app integration, and reports. Data flows through `LibraryRepository` → `MockLibraryRepository` with Riverpod providers — no inline mock data in screens.

| ID | Screen | Route |
|----|--------|-------|
| LB-01 | Dashboard | `/library/dashboard` |
| LB-02 | Catalog | `/library/catalog` |
| LB-03 | Issue | `/library/issues` |
| LB-04 | Returns | `/library/returns` |
| LB-05 | Members | `/library/members` |
| LB-06 | Fines | `/library/fines` |
| LB-07 | Digital Resources | `/library/resources` |
| LB-08 | Reports | `/library/reports` |

Bare `/library` redirects to `/library/dashboard`.

---

## Features Delivered

### LB-01 — Dashboard

- Six KPI tiles (total books, issued today, overdue, fines MTD, popular title, digital resources)
- Recent issues table with loan status chips
- Issue trend chart and category distribution panel
- Overdue warning banner with link to issues
- AI insight card with fines link

### LB-02 — Catalog

- Book catalog with ISBN, title, author, category, copies, shelf
- Derived KPI row (titles, total copies, available)
- Status filters (All, Available, Issued, Textbooks)

### LB-03 — Issue

- Active loan table with member, book, dates, status
- SIS student row navigation (`SIS-STU-*` IDs)
- Student App integration insight (My Books placeholder)

### LB-04 — Returns

- Return history with condition and fine calculation
- Finance FN-02 integration insight for library_fine fee head

### LB-05 — Members

- Students, teachers, and staff with active loan counts
- Blocked member status for fine limit enforcement
- SIS registry navigation

### LB-06 — Fines

- Overdue fine table with pending/paid/waived status
- Finance FN-02 fee head placeholder and FN-05 collections link
- Total pending fines KPI

### LB-07 — Digital Resources

- E-books, PDFs, links, and videos with class-level access
- Student App and Teacher App visibility columns
- Dual integration insight cards

### LB-08 — Reports

- Six-report catalog (RPT-LB-001 → RPT-LB-003 plus fines, digital, members)
- Monthly issue trend chart
- Overdue-by-class and popular-titles segment panels

## Repository Architecture

### Repository contract

`LibraryRepository` (`lib/core/repositories/interfaces/library_repository.dart`):

| Method | Returns |
|--------|---------|
| `getDashboard()` | `LibraryDashboardData` |
| `getCatalog()` | `List<LibraryBook>` |
| `getIssues()` | `List<LibraryIssueRecord>` |
| `getReturns()` | `List<LibraryReturnRecord>` |
| `getMembers()` | `List<LibraryMember>` |
| `getFines()` | `LibraryFinesData` |
| `getDigitalResources()` | `LibraryDigitalResourcesData` |
| `getReports()` | `LibraryReportsData` |

### Repository implementation

`MockLibraryRepository` (`lib/core/repositories/mock/mock_library_repository.dart`) — integrated mock data aligned with SIS student IDs (Arjun Patel `SIS-STU-10421`, Emma Thomas, Priya Sharma).

### Provider wiring

```
Screen → library*Provider → libraryRepositoryProvider → MockLibraryRepository
```

Registered in `lib/core/repositories/repository_providers.dart` as `libraryRepositoryProvider`.

Feature providers in `lib/features/library/library_providers.dart` with loading/error/empty `StateProvider` flags per screen.

- Student/Teacher app digital reader not implemented (route links only)
- Export/download buttons on reports are UI placeholders
