# Alumni MVP Release

**Version:** `v1.3-alumni-mvp`  
**Date:** June 2026  
**Codename:** Alumni MVP (AL-01 → AL-10)  
**Prior release:** Inventory MVP (v1.2)

---

## Overview

Alumni MVP delivers nine admin screens plus a mobile companion placeholder for alumni engagement: dashboard KPIs, SIS-linked registry, profile detail, events, donations, campaigns, mentorship, reports, and settings. Data flows through `AlumniRepository` → `MockAlumniRepository` with Riverpod providers — no inline mock data in screens.

| ID | Screen | Route |
|----|--------|-------|
| AL-01 | Dashboard | `/alumni/dashboard` |
| AL-02 | Alumni Registry | `/alumni/registry` |
| AL-03 | Alumni Profile | `/alumni/profile/:alumniId` (child route) |
| AL-04 | Events | `/alumni/events` |
| AL-05 | Donations | `/alumni/donations` |
| AL-06 | Campaigns | `/alumni/campaigns` |
| AL-07 | Mentorship | `/alumni/mentorship` |
| AL-08 | Reports | `/alumni/reports` |
| AL-09 | Settings | `/alumni/settings` |
| AL-10 | Mobile Companion | Settings section placeholder |

Bare `/alumni` redirects to `/alumni/dashboard`.

---

## Features Delivered

### AL-01 — Dashboard

- Six KPI tiles (total alumni, new graduates, donations MTD, campaigns, mentorship pairs, event RSVPs)
- Recent SIS graduates list with profile navigation
- Donation summary card with Finance ledger link
- Engagement metrics and AI insight card with SIS link

### AL-02 — Alumni Registry

- SIS-linked alumni directory (`SIS-STU-*` IDs)
- Engagement status filters (All, Active, Inactive, Pending)
- Row tap navigates to AL-03 profile

### AL-03 — Alumni Profile

- Child route (not in sub-nav) with custom breadcrumbs
- Employment history, donation history, mentorship role, events attended
- SIS profile and donations cross-links

### AL-04 — Events

- Event calendar with RSVP counts and status filters
- Upcoming, ongoing, completed event states

### AL-05 — Donations

- Donation ledger with Finance receipt IDs
- Finance FN-05 collections integration placeholder
- Status filters (Received, Pledged, Pending)

### AL-06 — Campaigns

- Fundraising campaigns with goal/raised progress
- Finance GL account codes (`FN-ALM-*`)

### AL-07 — Mentorship

- Mentor–mentee pairs with session counts
- Status filters and mentor profile navigation

### AL-08 — Reports

- Six-report catalog with download placeholders
- Donation trend chart (Finance integration)
- Engagement-by-batch segment panel
- Event attendance trend

### AL-09 — Settings

- SIS graduates auto-onboarding configuration
- Finance donations and campaign GL mapping
- Parent ecosystem placeholders

### AL-10 — Mobile Companion

- Dedicated settings section (sandbox placeholder)
- Push notifications and deep link route notes

## Repository Architecture

### Repository contract

`AlumniRepository` (`lib/core/repositories/interfaces/alumni_repository.dart`):

| Method | Returns |
|--------|---------|
| `getDashboard()` | `AlumniDashboardData` |
| `getAlumniRegistry()` | `List<AlumniRecord>` |
| `getAlumniDetail(alumniId)` | `AlumniDetail?` |
| `getEvents()` | `List<AlumniEvent>` |
| `getDonations()` | `List<AlumniDonation>` |
| `getCampaigns()` | `List<AlumniCampaign>` |
| `getMentorshipPairs()` | `List<MentorshipPair>` |
| `getReports()` | `AlumniReportsData` |
| `getSettings()` | `AlumniSettingsData` |

### Repository implementation

`MockAlumniRepository` (`lib/core/repositories/mock/mock_alumni_repository.dart`) — integrated mock data aligned with SIS student IDs (Arjun Patel `SIS-STU-10421`, Priya Sharma `SIS-STU-10415`, etc.).

### Provider wiring

```
Screen → alumni*Provider → alumniRepositoryProvider → MockAlumniRepository
```

Registered in `lib/core/repositories/repository_providers.dart` as `alumniRepositoryProvider` with `useApiRepositoriesProvider` swap to `ApiAlumniRepository`.

Feature providers in `lib/features/alumni/alumni_providers.dart` with loading/error/empty `StateProvider` flags per screen.

## Known Limitations

- No API integration — all data via `MockAlumniRepository` (API scaffolding throws `ApiNotConnectedException`)
- AL-10 mobile companion is a settings placeholder only (no dedicated `/alumni/mobile` route)
- Export/download buttons on reports are UI placeholders
- 80G tax receipt generation deferred to Finance FN-08
