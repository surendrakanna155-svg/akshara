# API Repository Scaffolding Release

**Version:** `v1.5-api-repository-scaffolding`  
**Date:** June 2026  
**Codename:** Dio-Ready API Layer Foundation  
**Prior release:** `v1.4-ControlCenter-MVP`

---

## Overview

Introduces API-ready repository scaffolding for all 11 ERP repository contracts. Screens, providers, routers, and widgets remain unchanged — swap from `Mock*Repository` to `Api*Repository` via `useApiRepositoriesProvider`.

---

## Features Delivered

### Network layer

| Component | Location |
|-----------|----------|
| `ApiConfig` | `lib/core/network/api_config.dart` |
| `createDioClient()` | `lib/core/network/dio_client.dart` |
| `dioProvider` | `lib/core/network/dio_provider.dart` |
| `useApiRepositoriesProvider` | `lib/core/repositories/repository_config.dart` |
| `ApiNotConnectedException` | `lib/core/repositories/api/api_exception.dart` |

### Per-module API scaffolding (×11)

Each module under `lib/core/repositories/api/{module}/`:

| Layer | File pattern |
|-------|--------------|
| DTO | `dto/{module}_dashboard_dto.dart` |
| Mapper | `mapper/{module}_mapper.dart` |
| Remote | `remote/{module}_remote_datasource.dart` |
| Repository | `api_{module}_repository.dart` |

**Modules:** admissions, finance, sis, management, transport, hr, hostel, library, inventory, alumni, control_center

### Provider wiring

```
repository_providers.dart
  if (useApiRepositoriesProvider) → api*RepositoryProvider
  else → Mock*Repository

api_repository_providers.dart
  *RemoteDataSourceProvider(Dio)
  api*RepositoryProvider
```

---

## Repository Architecture

**Data flow (mock — default):**

```
Screen → Provider → Repository Interface → Mock*Repository
```

**Data flow (API — when enabled):**

```
Screen → Provider → Repository Interface → Api*Repository → RemoteDataSource → Dio
                                              ↓
                                           Mapper → Domain models
```

`Api*Repository` methods throw `ApiNotConnectedException` until backend is wired. `*RemoteDataSource` methods throw `UnimplementedError`. No HTTP calls are made.

## Enabling API mode

```dart
// Override in tests or app bootstrap:
useApiRepositoriesProvider.overrideWith((ref) => true);
```

Configure Dio base URL via `createDioClient(baseUrl: ..., authToken: ..., schoolId: ...)`.
