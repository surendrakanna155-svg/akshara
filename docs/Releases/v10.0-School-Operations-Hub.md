# v10.0 — School Operations Hub

**Tag:** `v10.0-school-operations-hub`  
**Date:** June 2026

## Summary

Principal and management daily command center aggregating attendance, collections, communications, student/employee risk alerts, inventory distribution status, and fee payment requests into a single school health score with critical alerts and pending actions.

## Backend

| Area | Detail |
|------|--------|
| API | `GET /operations/hub` |
| Service | `operations_hub_service.ts` — cross-module SQL aggregates |
| Inputs | `attendance_records`, `finance_receipts`, `intel_communication_drafts`, `intel_student_risk_snapshots`, `employee_intelligence_snapshots`, inventory dashboard, `payment_requests` |
| Output | `schoolHealth` score (0–100), daily summary, widgets, alerts, pending actions |
| Router | `operations_router.ts` mounted in `api/index.ts` |
