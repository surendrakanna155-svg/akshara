# v10.1 — Book Distribution Platform

**Tag:** `v10.1-book-distribution-platform`  
**Date:** June 2026

## Summary

Extends the Inventory Distribution Engine (v9.7) with textbook-focused reporting, lost/damaged/missing lifecycle statuses, and kit-category breakdowns. Closes the Phase 4 gap for parent acknowledgement by linking v9.8 acknowledgements to distribution status transitions.

## Backend

| Area | Detail |
|------|--------|
| Schema | Extended `inv_student_distributions.status` — `missing`, `lost`, `damaged` |
| API | `GET /inventory/distribution/reports` |
| Reports | Pending, issued, replacement, lost, damaged counts + `byKitCategory` |
| Repository | `buildDistributionReports` in `inventory_distribution_repository.ts` |
| Parent ack | Status `parent_acknowledged` counted in issued metrics |

## Flutter

| Area | Detail |
|------|--------|
| Screen | `/inventory/distribution` — reports section on existing screen |
| Model | `InvDistributionReports` in `phase5_models.dart` |
| Provider | `distributionReportsProvider` |
| Repository | Wired via `Phase5RemoteDataSource.fetchDistributionReports` |
