# v10.3 — Achievement Promotion Engine

**Tag:** `v10.3-achievement-promotion-engine`  
**Date:** June 2026

## Summary

Workflow for school achievements: create → generate shareable assets → pending approval → approve → publish → track views/shares/downloads. Supports sports, academic, cultural, and custom achievement types with JSONB asset storage and analytics counters.

## Backend

| Area | Detail |
|------|--------|
| Table | `achievement_promotions` — status workflow + assets + analytics JSONB |
| API | `GET/POST /promotions` · `POST /promotions/:id/generate|approve|publish|track` |
| Router | `achievement_promotion_router.ts` |
| Repository | `achievement_promotion_repository.ts` — asset generation stub |
| Audit | `promotion.created`, `promotion.assets.generated`, `promotion.approved`, `promotion.published` |
