# v10.4 — Production Hardening

**Tag:** `v10.4-production-hardening`  
**Date:** June 2026  
**Prerequisite:** v9.8–v10.3 Phase 5 complete

## Summary

Production hardening release closing Phase 5 carryover gaps from the consolidated review: parent mobile polish, object storage for School Memories, structured promotion asset metadata, contract tests, staging verification script, and multi-industry vision design specs. No new business modules — hardening and design only.

## Phase B — Object Storage (School Memories)

Closes Priority B gap: memory media used placeholder storage URLs (v10.2 carryover).

| Area | Detail |
|------|--------|
| Migration | `20260622700000_v104_storage_foundation.sql` — `school-memories` bucket, RLS policies, `storage_path` / `cover_storage_path` / `share_token` columns |
| Service | `storage_service.ts` — signed upload (3600s TTL), download (900s TTL), path layout `{org}/{school}/{event}/{album}/{filename}` |
| API | `POST /memories/events/:id/upload/presign` · `POST /memories/events/:id/upload/confirm` · `GET /memories/media/:id/download` · `GET /memories/share/:token` |
| Handlers | `school_memories_handlers.ts` — presign → client upload → confirm → persist `storage_path` |
| Security | Bucket private; school write scope; school/parent/student read scope; tenant path prefix enforced |

**Path layout:** `{organization_id}/{school_id}/{event_id}/{album_id}/{filename}`
