# v12.1–v12.6 — Phase 9 School Platform Completion

**Release date:** June 2026  
**Phase:** Akshara Evolution Program — Phase 9  
**Flag:** `SCHOOL_COMPLETION_API_ENABLED=true` (with `ENABLE_API_MODE=true`)

## Summary

Completes school-platform adoption features on top of v12.0: class-subject matrix, lesson analytics, timetable optimization, branding theme integration, communication delivery bridge, and real-school pilot toolkit.

## Milestones

| Version | Capability | Backend | Flutter |
|---------|------------|---------|---------|
| v12.1 | Class ↔ Subject matrix, teacher allocation, workload | `class_subject_assignments`, `teacher_subject_assignments` | Subject Assignment UI |
| v12.2 | Lesson analytics (teacher + principal) | `syllabus_topics`, lesson log topic FK | Lesson Analytics screen |
| v12.3 | Timetable optimization | `GET /school/timetables/optimize` | Timetable Optimization screen |
| v12.4 | Branding → ThemeData | (existing `school_branding`) | Login, splash, parent shell, app theme |
| v12.5 | Communication completion | `communication_delivery_events`, template bridge | Delivery analytics; WhatsApp read-only for schools |
| v12.6 | Pilot toolkit | `GET /school/pilot/dashboard` | Pilot Dashboard screen |

## RBAC

New permissions: `viewSubjectAssignments`, `manageSubjectAssignments`, `viewLessonAnalytics`, `viewTimetableOptimization`, `viewCommunicationDelivery`, `manageCommunicationTemplates`, `viewPilotDashboard`, `managePlatformWhatsApp`.

School admins no longer have `manageWhatsAppProvider`; only super admin manages provider credentials via `managePlatformWhatsApp`.
