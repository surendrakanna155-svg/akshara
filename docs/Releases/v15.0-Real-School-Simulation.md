## Summary

Phase 20 closes gaps before the first real-school pilot by scaling demo data to **500 students / 500 parents**, extending seed and validation scripts, fixing mobile error states, adding journey and performance tests, and publishing pilot operator guides.

- Staff import: 1 principal + 20 teachers + 10 non-teaching (`schoolAdmin`)

- Extended `demo_school_validate.py`: school process audit + role journeys (admin, principal, teacher, parent, accountant, inventory)
