## Defects found & fixed

| Defect | Screen / widget | Fix |
|--------|-----------------|-----|
| RenderFlex overflow (teacher schedule row) | `today_schedule_card.dart` | Flexible row height, compact status chip |
| Fixed-height greeting / attendance cards | Teacher dashboard widgets | `minHeight` instead of fixed height |
| Hero card text overflow | Parent / student hero cards | `maxLines` + ellipsis |
| Child selector chip overflow | `AksharaChildSelectorChip` | `Flexible`, max width, ellipsis |
| KPI / status chip overflow | `AksharaKpiCard`, `AksharaStatusChip` | Ellipsis on values and labels |
| Quick action grid overflow at 1.5×–2.0× text | `AksharaQuickActionGrid` | Dynamic `childAspectRatio` + scaled `minHeight` |
| Event row / date box overflow at high text scale | `event_card.dart` | `minHeight` rows; `FittedBox` date box |
| Insight card fixed 88px clip | `AksharaInsightCard` | `IntrinsicHeight` + `minHeight` |
| Blank academic error section | `parent_dashboard_screen.dart` | `AksharaSectionError` with invalidate retry |
| Empty notices / events / homework / schedule | Mobile dashboard widgets | Section empty states with optional CTAs |
