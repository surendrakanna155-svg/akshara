# Release v18.6 — ERP Coverage Expansion

**Tag:** `v18.6-erp-coverage-expansion`  
**Date:** June 2026

## Objective

Raise real ERP business workflow coverage from ~38% toward 80%+ using Patrol deep tests, module coverage reporting, and targeted fixes for the four remaining ERP failures — without revisiting auth/OTP/login.

## What changed

### Phase 1 — Module coverage map

- `scripts/qa/generate_module_coverage_report.py` — parses `route_names.dart` + Patrol workflow inventory
- Reports: `qa/reports/module_coverage_v18_6.json`, `qa/reports/module_coverage_v18_6.md`
- 19 modules tracked (Attendance, Homework, Exams, Fees, Inventory, Admissions, SIS, HR, Transport, Library, Hostel, Communications, Reports, Analytics, Timetable, Management, Parent/Teacher/Student Experience)

### Phase 2 — Failure fixes

Stable sub-nav keys (`QaTestKeys.moduleSubNavTab`) wired in Finance, Management, SIS, Admissions, Inventory sub-nav widgets.

| Failure | Fix |
|---------|-----|
| Finance Reports | Sub-nav key + anchor `Export PDF` |
| Hostel | Anchor `Occupancy` (KPI above fold) |
| Management Analytics | Sub-nav key + anchor `Enrollment trend` |
| Enrollment Parent Step | `QaTestKeys.enrollmentContinueButton` + `tapEnrollmentContinue()` |

### Phase 3 — Expanded Patrol workflows

| File | Workflows |
