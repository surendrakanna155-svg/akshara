# v2.1 — Live Finance API Integration

**Release type:** API integration (Finance module only)  
**Status:** Complete  
**Tests:** 572 passing · Analyzer: 0 issues  
**Baseline:** v2.0 production readiness 79/100 → v2.1 **84/100**

## Summary

Finance is the **second live API module** (after Admissions v1.9). All 13 `FinanceRepository` methods are wired through Dio remote calls, DTO parsing, and domain mappers. Other ERP modules remain on mocks. Admissions API is unchanged.

### Activation

```dart
environmentProvider → enableApiMode: true
financeApiEnabledProvider → true
```

All other `*ApiEnabledProvider` flags remain `false` by default unless explicitly enabled.

## API Endpoints

| Repository method | HTTP | Path |
|-------------------|------|------|
| `getDashboard` | GET | `/finance/dashboard` |
| `getCollections` | GET | `/finance/collections` |
| `getDailySummary` | GET | `/finance/collections/daily-summary` |
| `getFeeStructures` | GET | `/finance/fee-structures` |
| `getAcademicYears` | GET | `/finance/academic-years` |
| `getStudentAccounts` | GET | `/finance/student-accounts` |
| `getInstallmentPlans` | GET | `/finance/installment-plans` |
| `getCollectionDetail` | GET | `/finance/collections/{id}` |
| `getDefaultersDashboard` | GET | `/finance/defaulters` |
| `getRefundRequests` | GET | `/finance/refunds` |
| `getDiscountsDashboard` | GET | `/finance/discounts` |
| `getReportsData` | GET | `/finance/reports` |
| `getSettings` | GET | `/finance/settings` |

Query parameters: `tenantId`, `schoolId`, `organizationId` from `RepositoryQuery`.  
`getFeeStructures` also sends `academicYear`.

## New infrastructure

### DTOs (`lib/core/repositories/api/finance/dto/`)

| File | Purpose |
|------|---------|
| `finance_dashboard_dto.dart` | Dashboard response |
| `finance_collections_dto.dart` | Collections, daily summary, detail |
| `finance_fee_structures_dto.dart` | Fee structures, academic years, plans |
| `finance_student_accounts_dto.dart` | Student fee accounts |
| `finance_defaulters_dto.dart` | Defaulters dashboard |
| `finance_refunds_dto.dart` | Refund requests |
| `finance_discounts_dto.dart` | Discounts dashboard |
| `finance_reports_dto.dart` | Reports catalog and trends |
| `finance_settings_dto.dart` | Settings sections |
| `finance_enum_codec.dart` | Enum string parsing |

Shared envelope parsing reuses `ApiEnvelopeDto` from Admissions DTO layer.

### Mapper (`finance_mapper.dart`)

100% coverage for all Finance domain models returned by `FinanceRepository`.

### Remote (`remote/`)

- `finance_api_paths.dart` — REST path constants
- `finance_remote_datasource.dart` — Dio GET calls (interceptors from `dioProvider`)

### Error UX (`lib/features/finance/finance_async_state.dart`)

- `FinanceViewState<T>` — loading / failure / empty / data
- `FinanceAsyncBody` — `AksharaErrorState.fromFailure()` + retry via `ref.invalidate`
- All 11 Finance screens updated
