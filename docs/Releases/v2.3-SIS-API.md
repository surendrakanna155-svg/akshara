# v2.3 SIS Live API Integration

Release date: 2026-06-07

## Summary

Converts the Student Information System (SIS) module from mock-only to production API-ready using the same repository architecture as Admissions v1.9 and Finance v2.1.

## Repository methods (5)

| Method | Endpoint | Domain model |
|--------|----------|--------------|
| `getDashboard` | `GET /sis/dashboard` | `SisDashboardData` |
| `getStudents` | `GET /sis/students` | `List<SisStudent>` |
| `getStudentProfile` | `GET /sis/students/{studentId}` | `SisStudentProfile` |
| `getAcademicAssignment` | `GET /sis/academic-assignment` | `SisAcademicAssignmentData` |
| `getAdmissionsConversion` | `GET /sis/admissions-conversion` | `SisAdmissionsConversionData` |

## DTO coverage

- `sis_dashboard_dto.dart`
- `sis_students_dto.dart`
- `sis_student_profile_dto.dart`
- `sis_academic_assignment_dto.dart`

## Remaining gaps

- Write operations (assignment save, conversion POST) not in scope
- Bulk assignment upload remains placeholder
- Admissions conversion in mock mode still reads admissions enrollments locally

## Non-goals

- Admissions, Auth, RBAC, route, or screen layout changes

## Readiness impact

SIS API client: **3.0 → 8.0 / 10** (estimated overall **+2**, 88 → 90/100)
