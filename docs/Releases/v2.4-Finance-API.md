# v2.4 Finance Live API Completion

Release date: 2026-06-07

## Summary

Completes Finance module API integration — all 13 `FinanceRepository` methods are fully wired through Dio, DTO parsing, domain mappers, ViewState providers, and screen retry UX. Builds on v2.1 scaffolding with v2.4 fee-assignment endpoint alignment and expanded test coverage.

## Activation

```dart
environmentProvider → enableApiMode: true
financeApiEnabledProvider → true
```

## Screen → Endpoint mapping (FN-01 – FN-11)

| Screen | Repository method | HTTP | Path |
|--------|-------------------|------|------|
| FN-01 Dashboard | `getDashboard` | GET | `/finance/dashboard` |
| FN-02 Fee Structures | `getFeeStructures`, `getAcademicYears` | GET | `/finance/fee-structures`, `/finance/academic-years` |
| FN-03 Student Accounts | `getStudentAccounts` | GET | `/finance/student-accounts` |
| FN-04 Fee Assignment | `getInstallmentPlans` | GET | `/finance/fee-assignment` |
| FN-05 Collections | `getCollections`, `getDailySummary` | GET | `/finance/collections`, `/finance/collections/daily-summary` |
| FN-06 Collection Detail | `getCollectionDetail` | GET | `/finance/collections/{id}` |
| FN-07 Defaulters | `getDefaultersDashboard` | GET | `/finance/defaulters` |
| FN-08 Refunds | `getRefundRequests` | GET | `/finance/refunds` |
| FN-09 Discounts | `getDiscountsDashboard` | GET | `/finance/discounts` |
| FN-10 Reports | `getReportsData` | GET | `/finance/reports` |
| FN-11 Settings | `getSettings` | GET | `/finance/settings` |

Query parameters: `tenantId`, `schoolId`, `organizationId` from `RepositoryQuery`.
