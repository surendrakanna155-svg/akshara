# v2.6 — Finance Write APIs

Release date: 2026-06-07

## Summary

Completes the Finance module write layer on top of v2.4 read APIs. Fee structures, student accounts, fee assignment, refunds, scholarships, and settings mutations now flow through the repository pattern with RBAC guards, audit metadata, and AsyncNotifier mutation providers.

## Architecture

```
Screen → finance_workflow_actions → AsyncNotifier mutation provider → FinanceRepository → ApiFinanceRepository → FinanceRemoteDataSource → Dio
```

- Feature flag: `financeApiEnabledProvider`
- RBAC: `canManageFinanceProvider` via `assertManageFinance`
- Audit: `recordFinanceAudit` with `financeHandoffSent` type + `module/action` metadata
- Errors: `ApiFailure` / `ApiFailureMapper` — no `ApiNotConnectedException`
