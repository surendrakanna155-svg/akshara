# v2.6 — SIS Write APIs

## Summary

Completes the SIS module write layer on top of v2.3 read APIs. Student registration, profile updates, academic assignment, and admissions conversion now flow through the repository pattern with RBAC guards and AsyncNotifier mutation providers.

## Repository methods added (5)

| Method | HTTP | Path |
|--------|------|------|
| `createStudent` | POST | `/sis/students` |
| `updateStudent` | PUT | `/sis/students/{studentId}` |
| `updateStudentStatus` | PATCH | `/sis/students/{studentId}/status` |
| `assignAcademicAssignment` | POST | `/sis/academic-assignment` |
| `convertAdmissionsEnrollment` | POST | `/sis/admissions-conversion` |

## Architecture

```
Screen → AsyncNotifier mutation provider → SisRepository → ApiSisRepository → SisRemoteDataSource → Dio
```

- Feature flag: `sisApiEnabledProvider`
- RBAC: `canManageSisProvider` via `assertManageSis`
- Errors: `ApiFailure` / `ApiFailureMapper` — no raw Dio exceptions reach UI
- Mock parity: `MockSisRepository` + `MockSisWriteStore`
