## Architecture

```
Screen → hrDashboardFutureProvider / transportDashboardFutureProvider
       → hrRepositoryProvider / transportRepositoryProvider
       → ApiHrRepository / ApiTransportRepository (when flags enabled)
       → HrRemoteDataSource / TransportRemoteDataSource
       → Dio + Tenant + Auth interceptors
```
