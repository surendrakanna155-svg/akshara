# v3.0 — Mobile Repository Layer

Release date: 2026-06-07

## Summary

Migrated Parent, Teacher, and Student apps from inline mock providers to the repository pattern (interface → mock | API stub).

## Repository Interfaces

| Module | Methods | Interface |
|--------|--------:|-----------|
| Parent | 12 | `ParentRepository` |
| Teacher | 10 | `TeacherRepository` |
| Student | 7 | `StudentRepository` |

## Architecture

- Mock repositories hold seed data (moved from providers)
- API repositories stub `ApiNotConnectedException` until mobile backend ships
- Feature flags: `parentApiEnabledProvider`, `teacherApiEnabledProvider`, `studentApiEnabledProvider`
- Providers use `FutureProvider` + `watchRepositoryFuture` (ERP pattern)
