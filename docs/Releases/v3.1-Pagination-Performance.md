# v3.1 — Pagination & Performance

Release date: 2026-06-07

## Summary

Server-side pagination in repository interfaces for Admissions, Finance, and SIS primary list endpoints. Virtualized DataTable widget for large lists.

## Pagination

| Module | Method | Return type |
|--------|--------|-------------|
| Admissions | `getLeads` | `PaginatedResult<AdmissionsLead>` |
| Finance | `getCollections` | `PaginatedResult<CollectionPayment>` |
| SIS | `getStudents` | `PaginatedResult<SisStudent>` |

## Infrastructure

- `PaginatedResult<T>` — `lib/core/repositories/paginated_result.dart`
- `RepositoryQuery.page` / `pageSize` (default 20)
- Remote datasources pass `page` + `pageSize` query params
- `AksharaVirtualizedDataTable` + `AksharaPaginationBar` shared widgets
