# v4.0 — Multi-Tenant Production SaaS (Client Foundation)

Release date: 2026-06-07

## Summary

Client-side production hardening for multi-tenant SaaS: tenant-scoped mock data, forced logout on unrecoverable 401, production environment flags, and mutation permission widget.

## Delivered

| Area | Change |
|------|--------|
| Tenant mock scoping | `TenantMockScope` filters seed data by tenant; applied to Admissions, Finance, SIS, HR mocks |
| Session expiry | `AuthInterceptor.onSessionExpired` → `authProvider.logout()` via `dioProvider` |
| Production env | `requireTls`, `requireAuthentication`, `disableDemoAuth` on `Environment.production` |
| Monitoring scaffold | `ClientMonitor` interface + `clientMonitorProvider` |
| Mutation RBAC widget | `AksharaManageAction` wraps `ManagePermissionGuard` for mutation buttons |
