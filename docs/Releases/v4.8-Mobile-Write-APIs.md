# v4.8 — Mobile Write APIs

Release date: 2026-06-07

## Summary

Added 10 mobile write methods across Parent (3), Teacher (6), and Student (1) repositories with full mock + API stacks, mutation providers, audit logging, and contract/integration tests.

## Architecture

```
Screen → *_mutations_provider → assertPermission + audit
      → *Repository write method → Api*Repository → RemoteDataSource → Dio
      → invalidate read FutureProviders
```
