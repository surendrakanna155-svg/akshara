# v6.1 Phase 5B — SIS Dashboard Aggregates

**Status:** Complete  
**Depends on:** Phase 5A SIS foundation, Phase 5C academic catalog  
**Deployment:** Edge Functions redeploy required (`GET /sis/dashboard`)

---

## Summary

Live SIS dashboard aggregates replace mock-only KPIs when `SIS_API_ENABLED=true`. Backend computes tenant-scoped KPIs, class/gender/section distributions, and recent enrollment/conversion lists from operational tables.

## Deliverables

| Area | Change |
|------|--------|
| Backend route | `GET /sis/dashboard` — `viewSis` + school scope |
| Repository | `sis_dashboard_repository.ts` — KPI subqueries + distribution GROUP BY |
| Mapper | `dashboardToApi` — camelCase envelope with `kpis`, distributions, `aiInsight` |
| Tenant probes | 4 dashboard isolation probes (org/parent/student deny; school allow) |
| Client | `HybridSisRepository.getDashboard` → API; mapper `_toDashboardFromApi` |
| Staging verify | `scripts/sis_staging_verify.sh` — payload shape + route checks |
| Tests | Deno unit tests (repository, handler, router); Flutter contract + integration |

## API payload (summary)

| Field | Description |
|-------|-------------|
| `totalStudents`, `activeStudents`, … | Raw KPI counts |
| `kpis` | UI-ready KPI cards (7 tiles) |
| `classDistribution`, `genderDistribution`, `sectionDistribution` | `{ label, count, percent }[]` |
| `recentEnrollments`, `recentStudents`, `recentConversionItems` | Last 10 rows |
| `aiInsight` | Derived summary string |
