# v8.0 — Academic Year Transition Engine

**Tag:** `v8.0-academic-year-transition`  
**Priority:** P1 — core school revenue driver  
**Status:** Implemented

---

## Summary

Schools can preview and execute academic year rollover: class mapping, student promotion, graduation, current-year switch, and source-year archive — with audit trail.

---

## API

| Method | Path | Permission |
|--------|------|------------|
| GET | `/academic/transitions/mapping-suggestions` | `viewSis` |
| POST | `/academic/transitions/preview` | `manageSis` |
| POST | `/academic/transitions/:id/execute` | `manageSis` |
| GET | `/academic/transitions/:id` | `viewSis` |

## Security

- School scope + RLS on transition jobs  
- Execute requires `manageSis`  
- Preview blocks execute when invalid rows present  
- Per-row SAVEPOINT on promotion
