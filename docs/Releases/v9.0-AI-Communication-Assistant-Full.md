# v9.0 — AI Communication Assistant (Full)

**Tag:** `v9.0-ai-communication-assistant-full`  
**Date:** June 2026

## Summary

Teachers select a communication scenario (absent, homework missing, low attendance, parent meeting, behavior, appreciation, fee reminder, exam reminder) and generate professional and parent-friendly drafts in eight languages with WhatsApp, SMS, and email channel formats. Supports custom-note rewrite and voice-note architecture hook (`transcription_stub_v1`).

## Deliverables

- Table: `intel_communication_drafts`
- API: `POST /intelligence/communication/generate`
- Flutter: Communication tab in `/intelligence`
- Audit: `communicationGenerated`
