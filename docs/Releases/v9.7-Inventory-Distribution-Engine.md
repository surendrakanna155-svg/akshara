# v9.7 — Inventory Distribution Engine

**Tag:** `v9.7-inventory-distribution-engine`  
**Date:** June 2026

## Summary

Complete student inventory lifecycle for books, uniforms, ID cards, belts, stationery, lab kits, and sports kits. Workflow: received → available → distributed → parent acknowledgement → replacement → payment → reissue. Finance integration via `payment_requests` for paid replacements.

## Deliverables

- Tables: `inv_catalog_items`, `inv_student_distributions`
- API: `/inventory/distribution/*` (dashboard, catalog, items, status, replacement)
- Flutter: `/inventory/distribution` screen
- Parent RLS read policy on distributions
- Permissions: `viewInventoryDistribution`, `manageInventoryDistribution`
- Audit/domain events for create, status change, replacement
