## Bugs fixed

### QA-001 (Critical) — OTP back button loop

**Before:** Back from OTP called `context.go(/login)` but `_authRedirect` immediately sent user back to OTP while `AuthStatus.otpPending`.

**After:**

- `AuthNotifier.cancelOtpPending()` clears pending state
- OTP screen app bar + `PopScope` call `_returnToLogin()` before navigation
- Tests: `test/features/auth/first_run_navigation_test.dart`

### QA-002 (High) — Staff OTP stale state

**After:** Staff OTP back resets `staffLoginProvider` and handles system back via `PopScope`.
