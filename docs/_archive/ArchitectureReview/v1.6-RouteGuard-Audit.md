# v1.6 Route Guard Audit

## Guard Types

| Guard | File | Behavior |
|-------|------|----------|
| `AuthenticatedGuard` | `route_guards.dart` | Requires `AuthStatus.authenticated` |
| `RoleGuard` | `route_guards.dart` | Requires `ErpRole` in allowed set |
| `PermissionGuard` | `route_guards.dart` | Requires single `Permission` |
| `ErpRouteGuard` | `route_guards.dart` | Location-based view permission check |
| `ControlCenterGuard` | `route_guards.dart` | SuperAdmin + `viewControlCenter` |

## Integration Points

1. **`AdminShell`** — wraps all ERP child routes with `ErpRouteGuard`
2. **`app_router.dart`** — `_canAccessRoute` uses `canAccessAdminErpShell()` (staff-only shell entry)
3. **Unauthorized UX** — `AccessDeniedScreen` → `AksharaErrorState(message: 'Access Denied')` with lock icon semantics
