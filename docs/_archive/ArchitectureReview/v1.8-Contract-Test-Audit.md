### What each test verifies

1. **Type conformance** — `mockRepo` and `apiRepo` both implement `*Repository`
2. **Signature parity** — `getDashboard` has matching `Future<T> Function({required RepositoryQuery query})` type
3. **DTO mapping parity** — Mock dashboard output serialized to JSON → `*DashboardDto.fromJson` → mapper → KPI labels/values match mock

Uses fake fixture JSON derived from mock data (no network calls).
