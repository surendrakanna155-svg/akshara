# v2.7 RBAC Security Audit

Date: 2026-06-07  
Score: **8.5 / 10**

## Before → After

| Area | v2.6 | v2.7 |
|------|------|------|
| Permission source | JWT claims + 12h cache | Sync service + version tracking |
| Route guards | view* only | view* + ManagePermissionGuard + ApprovePermissionGuard |
| Mutation RBAC | Partial (feature providers) | Centralized assertManage/Approve helpers |
| Denied access audit | ErpRouteGuard only | All manage/approve guards + metadata |
| Cache invalidation | Manual TTL | PermissionCacheService + refresh triggers |

## Services Added

- `PermissionCacheService` — read/write/invalidate with version bump
- `PermissionSyncService` — server fetch via auth repository
- `PermissionRefreshService` — login, refresh, app resume hooks
- `mutation_permission_validator.dart` — throws `ApiFailureException` on deny
