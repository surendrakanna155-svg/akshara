## Findings

### P0 — Duplication creating bugs

| ID | Finding |
|----|---------|
| WIDGET-P0-01 | **DataTable Material ancestor** — fixed in newer modules; inconsistent in older admissions tables — risk of runtime error if `onSelectChanged` added without `Material` wrapper |
| WIDGET-P0-02 | **None confirmed** — no active duplicate-widget bugs found in test suite |

### P1 — High-value consolidations

| ID | Finding | Priority |
|----|---------|----------|
| WIDGET-P1-01 | Extract `ErpModuleScaffold` + `ErpSubNav` | Highest ROI |
| WIDGET-P1-02 | Extract `AksharaResponsiveTable<T>` | Reduces 65+ table implementations |
| WIDGET-P1-03 | Move `FinanceResponsiveGrid` to `lib/shared/layout/` | Already de facto shared |
| WIDGET-P1-04 | Shared `AksharaSettingsSection` | 9 duplicate settings UIs |
| WIDGET-P1-05 | `statusChipFor(Enum)` extension | 45 wrapper classes |

| WIDGET-P2-01 | Unify `AdmissionsResponsiveGrid` / `SisResponsiveGrid` → `FinanceResponsiveGrid` |
