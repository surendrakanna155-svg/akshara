**Date:** 2026-06-05

## Executive summary

The network layer moves from static scaffold configuration to a **production-shaped interceptor pipeline** with environment-driven base URLs, live tenant/token accessors, request tracing, and standardized error mapping.

**Network readiness score: 78 / 100** (↑ from ~35/100 at v1.7)

| Environment | Network status |
|-------------|----------------|
| Mock-only (default) | **READY** — interceptors wired but unused for data |
| Staging API (flags on) | **PARTIAL** — HTTP fires; most endpoints unimplemented |
| Production | **NOT READY** — no backend, no cert pinning |

## Interceptor pipeline

Order in `DioClient` (request → response):

```
Request  → CorrelationIdInterceptor
         → TenantInterceptor
         → AuthInterceptor
         → [LogInterceptor if enableLogging]
Response ← ApiErrorInterceptor (onError)
```

### AuthInterceptor — **PASS**

| Requirement | Status | Notes |
|-------------|--------|-------|
| JWT bearer token | ✅ | `Authorization: Bearer <accessToken>` |
| Token refresh hook | ✅ | `TokenRefreshCallback` + 401 retry via `QueuedInterceptor` |
| Anonymous mode | ✅ | `allowAnonymous` skips auth when no token |
| Expired token pre-request refresh | ✅ | Checks `AuthTokens.isExpired` before send |

**Gap:** Refresh callback is provider-pluggable but not connected to a real auth server.

### TenantInterceptor — **PASS**

| Header | Source |
|--------|--------|
| `X-Tenant-Id` | `TenantContext.tenantId` via live accessor |
| `X-School-Id` | `TenantContext.schoolId` via live accessor |

Resolves v1.7 finding **P1-04** (static tenant header at client creation).

### CorrelationIdInterceptor — **PASS**

Generates `X-Correlation-Id` values prefixed with `ak-` for distributed tracing. Injectable `Random` for tests.

### ApiErrorInterceptor — **PASS**

Maps `DioException` types and HTTP status codes to `ApiFailureException` via `ApiFailureMapper`:

| Dio / HTTP | `ApiFailureType` |
|------------|------------------|
| Connection / send / receive errors | `network` |
| Timeouts | `timeout` |
| 401 | `unauthorized` |
| 403 | `forbidden` |
| 5xx | `server` |
| Other | `unknown` |
