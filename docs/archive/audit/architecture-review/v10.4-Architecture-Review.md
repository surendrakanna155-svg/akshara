## Review Areas (12)

### 1. Architecture & Module Boundaries

Hardening extends existing Phase 5 modules without new routers or circular dependencies. Storage service is shared utility under `_shared/storage/`. Parent experience service composes Student 360 + intelligence reads — no duplicate aggregates. Promotion asset service is pure metadata generator consumed by existing promotion handlers.

**Score impact:** +1 (clean extension pattern)

### 2. API Routing & Envelope Pattern

New memory routes registered in `school_memories_router.ts`: `upload/presign`, `upload/confirm`, `media/:id/download`, `share/:token`. Parent hub payload extended in-place — no breaking path changes. All handlers return standard `envelope()` / `errorEnvelope()`.

**Score impact:** Neutral (consistent)

### 3. Repository Layer Parity

Phase 5 mapper updated for `homeworkIntelligence` and extended `guidance.reports`. Mock repositories seed guidance reports and asset bundles matching API shape. Contract test file validates mock contract surface.

**Score impact:** +2 (closes Phase 5 parity gap)

### 4. RBAC & Permission Matrix

No new permission slugs required. Memory upload routes require school scope write. Parent hub remains `viewParentExperience`. Staging script validates parent 403 on `/operations/hub`.

**Score impact:** Neutral

### 5. RLS & Tenant Isolation

Storage policies enforce `app_current_tenant_id()` path prefix on `school-memories` bucket. Existing memory table RLS unchanged. Share token index added for scoped public links without bypassing tenant checks on authenticated routes.

**Score impact:** +1 (storage RLS added)

### 6. Storage & Media Security

Private bucket with MIME allowlist (jpeg, png, webp, gif, mp4, webm). 50 MB file size limit. Signed upload URLs expire in 3600s; download URLs in 900s. Service role used only in Edge handlers — never exposed to client.

**Score impact:** +2 (production-ready upload pipeline)

### 7. Parent Mobile Experience

Six-tab hub with guidance excerpts, homework intelligence, and inventory ack/replacement UX. Closes v9.8 Priority B gap (guidance availability flag only). Overview surfaces pending ack count with drill-down.

**Score impact:** +2 (production polish)

### 8. Promotion Asset Pipeline

Structured six-format bundle with dimensions and channel-specific captions. Metadata persisted in `achievement_promotions.assets` JSONB. Image URLs deferred — `imageGenerationReady: true` signals future Copilot integration. Preview screen renders metadata without requiring CDN.

**Score impact:** +1 (structured vs stub)

### 9. Audit & Domain Events

No new audit event types. Existing promotion and memory events cover generate/publish/upload confirm paths. Upload confirm should emit `memories.media.uploaded` in follow-up (documented, not blocking).

**Score impact:** −1 (minor audit gap)
