## Technical fix — native assets / xcrun

**Root cause:** Dart `hooks_runner` filters subprocess environment and does **not** forward `DEVELOPER_DIR`. The `objective_c` package calls `xcrun --show-sdk-path`, which fails without `DEVELOPER_DIR` when `PATH` is minimal.

**Solution:** `scripts/ios/xcrun` wrapper on `PATH` (whitelisted by hooks_runner) that exports `DEVELOPER_DIR` before invoking `/usr/bin/xcrun`.

**Risk:** Low — wrapper is idempotent; real `xcrun` still executes. Hardcoded Xcode path matches build Mac standard location.
