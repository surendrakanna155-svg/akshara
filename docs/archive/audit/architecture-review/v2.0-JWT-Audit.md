# v2.0 JWT Audit

**Date:** 2026-06-05  
**Scope:** JWT decode, refresh, session manager, interceptor integration

## Summary

JWT lifecycle is now **client-complete** with decode, expiry validation, scheduled refresh, and logout-on-expiry — still without signature verification or live refresh endpoint.

**JWT readiness: 72 / 100** (↑ from ~25/100 at v1.7)

## Components

| Component | Coverage |
|-----------|----------|
| `JwtDecoder` | Payload parse, exp/iat, mock builder |
| `TokenRefreshService` | shouldRefresh, refreshIfNeeded, schedule |
| `AuthSessionManager` | restore, claims sync, schedule hook |
| `AuthInterceptor` | Bearer attach, 401 retry (unchanged) |
| `tokenRefreshCallbackProvider` | Mock refresh JWT (v2.0 wired) |

## Lifecycle flow

```
Login → AuthTokens persisted
      → AuthSessionManager.scheduleTokenRefresh
      → TokenRefreshService fires before expiry
      → refreshCallback → new tokens → persist
      → on expiry failure → logout
```

Cold start:

```
resolveSession → restoreSession → refresh if expired → schedule
```
