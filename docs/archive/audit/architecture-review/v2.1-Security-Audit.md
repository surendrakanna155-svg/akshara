## 1. Executive Summary

v2.0 delivered production-**shaped** client security: JWT lifecycle, token refresh scheduling, staff OTP UX, RBAC matrix, route guards, tenant headers, and local audit logging. **Authentication remains mock end-to-end** — no live auth server, no signature verification, client-selectable ERP roles, and server permission cache is unused.

## 3. Refresh Flow — **6 / 10**

### Triggers

1. Cold start — expired access token on `resolveSession()`
2. Scheduled timer — ~5 min before JWT expiry
3. Pre-request — `AuthInterceptor.onRequest`
4. 401 retry — `AuthInterceptor.onError` (once)

### Gaps

| ID | Gap | Severity |
|----|-----|----------|
| SEC-R01 | `tokenRefreshCallbackProvider` returns mock JWT — no HTTP | P0 |
| SEC-R02 | Failed refresh on non-expired token → session continues stale | P1 |
| SEC-R03 | 401 + refresh fail → no forced logout | P1 |
| SEC-R04 | No refresh token rotation | P1 |
| SEC-R05 | Claims-only restore without bearer token allowed | P1 |
