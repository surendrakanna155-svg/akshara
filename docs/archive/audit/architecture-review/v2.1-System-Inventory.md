## 1. Executive Summary

Akshara ERP is a **multi-surface Flutter monorepo**: mobile apps (Parent, Teacher, Student), a web ERP admin shell (11 business modules + Control Center), and shared platform infrastructure (auth, RBAC, networking, repositories). **Two of eleven** ERP repository domains have live read-only API implementations; the remainder remain mock-backed with API scaffolding.

| Surface | Data layer | API connected |
|---------|------------|---------------|
| ERP admin (11 modules) | Repository interfaces + mocks/API swap | Admissions ✅ · Finance ✅ · 9 stubs |
| Control Center | Repository interface + mock | Stub only |
| Parent / Teacher / Student | Inline mock providers | ❌ No repository layer |
