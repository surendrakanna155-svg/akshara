## Implementation Review

### DTO Layer

`AuditBatchUploadRequestDto` serializes `AuditEvent` domain objects to OpenAPI `AuditEventPayload` shape:
- Required: `id`, `type`, `timestamp`
- Optional: `userId`, `tenantId`, `schoolId`, `correlationId`, `category`, `metadata`

### Remote Layer

`AuditRemoteDataSource.uploadBatch()`:
- Empty batch → returns `acceptedCount: 0` without network call
- Uses `ApiEnvelopeDto` error handling pattern
- Returns `AuditBatchUploadResponseDto` with `acceptedCount` + `rejectedIds`

### Provider Layer

`resolveAuditBatchUploader(Ref ref)`:
- API disabled → `UnimplementedError` (preserves v2.7 behavior)
- API enabled → delegates to `AuditRemoteDataSource`

### Feature Flag

```dart
final auditApiEnabledProvider = Provider<bool>((ref) => false);
```

Requires both `enableApiModeProvider` and `auditApiEnabledProvider` for live upload.
