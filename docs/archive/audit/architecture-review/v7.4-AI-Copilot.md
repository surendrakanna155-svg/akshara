# v7.4 AI Copilot — Architecture Review

**Score:** 91/100 · **Status:** Complete

## Summary

AI Copilot adds a read-only conversational layer over ERP data. Handlers authenticate via JWT, enforce `viewAiCopilot` / `runAiCopilot` plus module-scoped view permissions, load tenant-safe context through the context engine, and persist sessions per user. OpenAI is optional; stub mode supports dev, contract tests, and staging without credentials.

## Security

- Read-only by design — no mutation audit paths; handlers never call write repositories
- Assistant list filtered by module view permissions
- Context engine returns `access: denied` for modules without permission
- Sessions scoped to `organization_id`, `school_id`, and `user_id`
