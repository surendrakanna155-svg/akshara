## Known Limitations

- **Mock data only** — All admissions providers use in-memory fixtures; no API or persistence layer
- **Actions are placeholders** — Approve/Reject, Send to Finance, Export, and settings toggles show UI only (SnackBar or no-op)
- **No real Finance integration** — Fee handoff previews student ID and SIS status but does not call Finance module APIs
- **No Student SIS write** — SIS handoff labels are mock; no cross-module event bus yet
- **No Marketing handoff** — Campaign column read-only banner present; MK-02 integration not wired
- **No principal role split** — Staff role accesses full admin ERP; principal-only approval queue not gated
- **Export** — Reports export button is a placeholder
- **Enrollment wizard** — Form state is local; no server-side validation or document attachment
- **Settings** — Configuration switches do not persist

## Recommended Next: Finance MVP Phase 1

With Admissions MVP complete, the highest-value next module is **Finance MVP Phase 1**:

1. **Finance shell** — Reuse `AdminShell` under `/finance` with sub-navigation
2. **Fee structure catalog** — Consume handoffs from AD-08
3. **Student fee accounts** — Link to `previewStudentId` / admission numbers
4. **Installment schedule** — Basic plan assignment (mock → API)
5. **Receipt placeholder** — Prepare for parent app fee sync (PA-03)

This unblocks the post-approval flow: **Admissions approve → Fee handoff → Finance account → SIS activation → Parent fee visibility**.
