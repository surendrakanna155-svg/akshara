## Admissions Integration

| Integration point | Implementation |
|-------------------|----------------|
| Handoff queue data | `financeHandoffQueueProvider` consumes `admissionsApprovedHandoffsProvider` |
| Status updates | `feeHandoffStatusOverridesProvider` in admissions fee handoff provider; Finance assignment sets `completed` |
| FN-01 dashboard queue | Compact handoff table with Assign CTA → FN-04 |
| FN-04 assignment | Full workflow: structure, installment plan, transport/hostel add-ons, generate account preview |
| SIS preview key | `previewStudentId` displayed in assignment panel |
| Bidirectional sync | Admissions AD-08 reflects updated handoff status after Finance completes assignment |

## Known Limitations

- **Mock data only** — All finance providers use in-memory fixtures; no API or persistence
- **Create/Edit placeholders** — Fee structure create/edit buttons are UI-only
- **Reconciliation placeholder** — FN-05 reconciliation button does not open a workflow
- **No payroll, accounting, expenses, budgeting** — Out of Phase 1 scope per spec
- **No HR or transport billing** — Deferred to future finance phases
- **No payment recording** — Collections list is read-only; no cash/UPI entry dialog
- **No defaulter drill-down** — Dashboard warning banner action is a no-op
- **No parent app write-back** — Fee account generation does not update `parentFeesProvider`
- **No Student SIS write** — SIS handoff labels remain mock strings
- **Export/reporting** — FN-11 financial reports not started
