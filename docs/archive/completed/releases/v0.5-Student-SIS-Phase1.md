| Area | Implementation |
|------|----------------|
| Shell | `AdminShell` + `AdminContentScaffold` via `SisModuleScaffold` |
| State | Riverpod providers with mock data, loading/empty/error flags |
| Routing | GoRouter nested shell under `/sis` |
| Responsive | Desktop 1440, tablet collapsed rail, mobile drawer + card fallbacks |
| Shared widgets | `AksharaKpiCard`, `AksharaStatusChip`, `AksharaInsightCard`, `AksharaSectionHeader`, loading/empty/error states |

## Admissions Integration

| Integration point | Implementation |
|-------------------|----------------|
| Enrollment records | `admissionsPendingEnrollmentsProvider` mock AD-05 outputs |
| Conversion status | `enrollmentConversionOverridesProvider` shared with admissions |
| SIS-01 dashboard queue | Compact conversion queue with Convert CTA |
| SIS-05 workflow | Generate admission number, SIS student ID, class preview, mark converted |
| Bidirectional sync | Admissions enrollment list reflects `converted` status after SIS action |

## Known Limitations

- **Mock data only** — No API or persistence layer
- **Export placeholder** — Registry export button is UI-only
- **Promote/transfer/bulk assignment** — SIS-04 workflow buttons are placeholders
- **No TC generation** — Out of Phase 1 scope
- **No alumni, library, hostel, transport allocation** — Deferred
- **No ID card printing** — Deferred
- **No parent app write-back** — SIS conversion does not create parent accounts
- **Converted students not appended to registry list** — Conversion preview stored in state only; registry uses static mock
- **Document vault** — SIS-07 not started; profile shows summary counts only
