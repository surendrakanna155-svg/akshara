# HR MVP Release

**Version:** `v0.9-hr-mvp`  
**Date:** June 2026  
**Codename:** HR MVP (HR-01 → HR-09)  
**Prior release:** Transport MVP (v0.8)

---

## Overview

HR MVP delivers nine admin screens for human resources: dashboard KPIs, employee registry with profile detail, staff attendance, leave management, payroll with Finance integration placeholder, recruitment pipeline, performance reviews, and module settings. Data flows through `HrRepository` → `MockHrRepository` with Riverpod providers — no inline mock data in screens.

| ID | Screen | Route |
|----|--------|-------|
| HR-01 | Dashboard | `/hr/dashboard` |
| HR-02 | Employees | `/hr/employees` |
| HR-03 | Employee Profile | `/hr/employees/:employeeId` |
| HR-04 | Attendance | `/hr/attendance` |
| HR-05 | Leave Management | `/hr/leave` |
| HR-06 | Payroll | `/hr/payroll` |
| HR-07 | Recruitment | `/hr/recruitment` |
| HR-08 | Performance | `/hr/performance` |
| HR-09 | Settings | `/hr/settings` |

Bare `/hr` redirects to `/hr/dashboard`.

## Features Delivered

### HR-01 — Dashboard

- Six KPI tiles (total employees, present today, on leave, open positions, avg attendance MTD, reviews due)
- Headcount and attendance trend charts
- Pending leave queue with link to leave screen
- Recruitment snapshot mini-pipeline
- AI insight card with employee registry link
- Management KPI feed note (teacher attendance → MG-01)

### HR-02 — Employees

- Employee directory with department, designation, phone, status
- Status filters (All, Active, On leave, Teachers)
- Row tap navigates to employee profile
- Teacher app integration insight (Priya Sharma, Mrs. Rao, Mr. Patel)

### HR-03 — Employee Profile

- Child route under employees (not in sub-nav)
- Profile header with designation, class, manager, contact
- Leave balances and recent attendance
- Document list and module integration notes
- Teacher app / Finance / Transport cross-links in mock data

### HR-04 — Staff Attendance

- Daily attendance roster with geo + face verification columns
- Status filters (All, Present, Late, On leave)
- Weekly attendance trend and department breakdown
- Teacher app TA-01 sync note

### HR-05 — Leave Management

- Leave request table with approver and status
- Status filters (All, Pending, Approved, Rejected)
- Leave-by-type segment panel
- Principal / Teacher app workflow integration note

### HR-06 — Payroll

- Payroll run catalog (May/June 2026)
- Employee payroll entries with basic/allowances/deductions/net
- Salary disbursement trend chart
- Finance module link (FN-05 salary ledger placeholder)

### HR-07 — Recruitment

- Candidate pipeline table (Applied → Joined stages)
- Stage filters and pipeline segment panel
- Hiring trend chart
- Open positions count

### HR-08 — Performance

- Performance review roster with cycle, rating, due date
- Status filters (All, In progress, Completed, Overdue)
- Rating distribution and completion trend
- Management MG-06 integration insight

### HR-09 — Settings

- Attendance verification (geo-fence, face verify for teachers)
- Leave policy and principal approval rules
- Payroll & Finance integration placeholders
- Teacher app and Management KPI sync settings

## Repository Architecture

### Repository contract

`HrRepository` (`lib/core/repositories/interfaces/hr_repository.dart`):

| Method | Returns |
|--------|---------|
| `getDashboard()` | `HrDashboardData` |
| `getEmployees()` | `List<HrEmployee>` |
| `getEmployeeDetail(id)` | `HrEmployeeDetail?` |
| `getAttendance()` | `HrAttendanceData` |
| `getLeave()` | `HrLeaveData` |
| `getPayroll()` | `HrPayrollData` |
| `getRecruitment()` | `HrRecruitmentData` |
| `getPerformance()` | `HrPerformanceData` |
| `getSettings()` | `HrSettingsData` |

### Repository implementation

`MockHrRepository` (`lib/core/repositories/mock/mock_hr_repository.dart`) — integrated mock data aligned with Teacher module names (Priya Sharma `kMockTeacherName`, Mrs. Rao, Mr. Patel), Transport driver Ramesh Kumar, and Management KPI references.

### Provider wiring

```
Screen → hr*Provider → hrRepositoryProvider → MockHrRepository
```

Registered in `lib/core/repositories/repository_providers.dart` as `hrRepositoryProvider` with `useApiRepositoriesProvider` swap path.

Feature providers in `lib/features/hr/hr_providers.dart` with loading/error/empty `StateProvider` flags per screen.
