# Inventory MVP Release

**Version:** `v1.2-inventory-mvp`  
**Date:** June 2026  
**Codename:** Inventory MVP (INV-01 → INV-08)  
**Prior release:** Library MVP (v1.1)

---

## Overview

Inventory MVP delivers eight admin screens for asset and procurement operations: dashboard KPIs, asset registry, category catalog, cross-module allocation, maintenance scheduling, procurement orders, vendor directory, and reports. Data flows through `InventoryRepository` → `MockInventoryRepository` with Riverpod providers — no inline mock data in screens.

| ID | Screen | Route |
|----|--------|-------|
| INV-01 | Dashboard | `/inventory/dashboard` |
| INV-02 | Assets | `/inventory/assets` |
| INV-03 | Categories | `/inventory/categories` |
| INV-04 | Allocation | `/inventory/allocation` |
| INV-05 | Maintenance | `/inventory/maintenance` |
| INV-06 | Procurement | `/inventory/procurement` |
| INV-07 | Vendors | `/inventory/vendors` |
| INV-08 | Reports | `/inventory/reports` |

Bare `/inventory` redirects to `/inventory/dashboard`.

---

## Features Delivered

### INV-01 — Dashboard

- Six KPI tiles (total assets, allocated, under maintenance, low stock, open PO value, total asset value)
- Recent activity feed with Finance, HR, Hostel, and Library module links
- Low stock alerts with procurement link
- Module integrations card and AI insight with Finance link

### INV-02 — Assets

- Asset registry with tag, category, location, value, status, Finance asset ID
- Derived KPI row (assets shown, allocated, total value)
- Status filters (All, Available, Allocated, Maintenance, Retired)

### INV-03 — Categories

- Category catalog with type, asset count, total value, depreciation rate
- Type filters (All, Equipment, Furniture, Electronics, Consumables)

### INV-04 — Allocation

- Cross-module allocations with HR employee IDs (`HR-EMP-*`), Hostel blocks, Library sections
- Status filters (All, Active, Pending return, Overdue)
- Integration insight card linking to Hostel and HR

### INV-05 — Maintenance

- Maintenance schedule with technician, HR technician ID, estimated cost
- Finance budget code column (`FN-BUD-MAINT-2026`)
- Status filters (All, Scheduled, In progress, Overdue)

### INV-06 — Procurement

- Purchase order table with Finance PO IDs (`FN-PO-*`)
- Status filters (All, Draft, Ordered, Received)
- Finance PO integration link

### INV-07 — Vendors

- Vendor directory with GST, active POs, total spend, Finance vendor ID
- Status filters (All, Active, Pending, Inactive)

### INV-08 — Reports

- Six-report catalog with download placeholders
- Asset value trend chart
- Allocation-by-department segment panel
- Procurement spend trend chart

## Repository Architecture

### Repository contract

`InventoryRepository` (`lib/core/repositories/interfaces/inventory_repository.dart`):

| Method | Returns |
|--------|---------|
| `getDashboard()` | `InventoryDashboardData` |
| `getAssets()` | `List<InventoryAsset>` |
| `getCategories()` | `List<InventoryCategory>` |
| `getAllocations()` | `List<InventoryAllocation>` |
| `getMaintenanceRecords()` | `List<InventoryMaintenanceRecord>` |
| `getProcurementOrders()` | `List<InventoryProcurementOrder>` |
| `getVendors()` | `List<InventoryVendor>` |
| `getReports()` | `InventoryReportsData` |

### Repository implementation

`MockInventoryRepository` (`lib/core/repositories/mock/mock_inventory_repository.dart`) — integrated mock data with Finance (`FN-AST-*`, `FN-PO-*`, `FN-VND-*`), HR (`HR-EMP-*`), Hostel (Block A mess furniture), and Library (RFID scanner) placeholders.

### Provider wiring

```
Screen → inventory*Provider → inventoryRepositoryProvider → MockInventoryRepository
```

Registered in `lib/core/repositories/repository_providers.dart` as `inventoryRepositoryProvider` with `useApiRepositoriesProvider` swap to `ApiInventoryRepository`.

Feature providers in `lib/features/inventory/inventory_providers.dart` with loading/error/empty `StateProvider` flags per screen.

## Integrations

| Module | Integration |
|--------|-------------|
| **Finance** | Asset values (`FN-AST-*`), PO IDs (`FN-PO-*`), vendor IDs (`FN-VND-*`), maintenance budget codes; dashboard KPI and insight links |
| **HR** | Employee equipment allocation (`HR-EMP-101`, `HR-EMP-108`); maintenance technician IDs; allocation screen HR directory link |
| **Hostel** | Hostel mess furniture allocation (Block A); maintenance for Hostel Block B AC; dashboard activity link |
| **Library** | RFID scanner allocation with library section; library books procurement draft PO; dashboard activity link |

## Known Limitations

- No API integration — all data via `MockInventoryRepository`
- `ApiInventoryRepository` scaffolding throws `ApiNotConnectedException` per method
- Export/download buttons on reports are UI placeholders
- Barcode/RFID scanning not implemented
- No real-time stock level sync with procurement
