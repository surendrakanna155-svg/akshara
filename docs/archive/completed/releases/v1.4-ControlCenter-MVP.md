# Control Center MVP Release

**Version:** `v1.4-control-center-mvp`  
**Date:** June 2026  
**Codename:** Control Center MVP (ACC-01 → ACC-12)  
**Prior release:** Alumni MVP (v1.3)

---

## Overview

Control Center MVP delivers twelve platform admin screens for Akshara Super Admin: dashboard KPIs, schools registry, subscriptions, billing, sales CRM, support tickets, customer success, white label, usage analytics, platform monitoring, roles & permissions, and settings. Data flows through `ControlCenterRepository` → `MockControlCenterRepository` with Riverpod providers — no inline mock data in screens.

| ID | Screen | Route |
|----|--------|-------|
| ACC-01 | Dashboard | `/control-center/dashboard` |
| ACC-02 | Schools | `/control-center/schools` |
| ACC-03 | Subscriptions | `/control-center/subscriptions` |
| ACC-04 | Billing | `/control-center/billing` |
| ACC-05 | CRM | `/control-center/crm` |
| ACC-06 | Support | `/control-center/support` |
| ACC-07 | Success | `/control-center/success` |
| ACC-08 | White Label | `/control-center/white-label` |
| ACC-09 | Usage Analytics | `/control-center/analytics` |
| ACC-10 | Platform Monitoring | `/control-center/monitoring` |
| ACC-11 | Roles & Permissions | `/control-center/roles` |
| ACC-12 | Settings | `/control-center/settings` |

Bare `/control-center` redirects to `/control-center/dashboard`.

## Features Delivered

### ACC-01 — Dashboard

- Seven KPI tiles (total schools, active, trial, expiring, MRR, ARR, churn risk)
- School growth and revenue trend charts
- Plan distribution segment panel
- ERP module adoption chips linking to all school modules
- Platform PII privacy banner (`AksharaWarningBanner`)
- AI insight card with customer success link

### ACC-02 — Schools

- Multi-school registry with plan, student counts (aggregates only), MRR, health score
- Status filters (All, Active, Trial, Churn risk)
- Drill to Management dashboard placeholder

### ACC-03 — Subscriptions

- Standard, Premium, Enterprise plan cards with dedicated DB flag
- Plan distribution and renewal metrics

### ACC-04 — Billing

- MRR/ARR/outstanding summary
- Revenue trend and by-plan breakdown
- Invoice table

### ACC-05 — CRM

- School-as-customer sales pipeline (distinct from Admissions AD-*)
- Stage distribution and active deals table

### ACC-06 — Support

- Ticket table with SLA timers and status filters
- School link (no student PII)

### ACC-07 — Success

- Per-school adoption score, renewal probability, churn risk
- Low-usage module alerts and AI churn insight

### ACC-08 — White Label

- Per-school logo, primary color, custom domain, login background placeholders

### ACC-09 — Analytics

- School and student growth trends (counts only)
- ERP module usage and marketing attribution

### ACC-10 — Monitoring

- Service health cards (API, Auth, Multi-tenant DB, Notifications)
- Feature flags list

### ACC-11 — Roles

- Platform roles (Super Admin, Director, Sales, Support)
- Permission group chips

### ACC-12 — Settings

- Feature flags, API rate limits, maintenance mode
- Multi-school architecture placeholders (Supabase RLS, Enterprise DB)

## Repository Architecture

### Repository contract

`ControlCenterRepository` (`lib/core/repositories/interfaces/control_center_repository.dart`):

| Method | Returns |
|--------|---------|
| `getDashboard()` | `ControlCenterDashboardData` |
| `getSchools()` | `List<PlatformSchool>` |
| `getSubscriptions()` | `ControlCenterSubscriptionsData` |
| `getBilling()` | `ControlCenterBillingData` |
| `getCrmPipeline()` | `ControlCenterCrmData` |
| `getSupportTickets()` | `List<SupportTicket>` |
| `getCustomerSuccess()` | `ControlCenterSuccessData` |
| `getWhiteLabelConfigs()` | `List<WhiteLabelConfig>` |
| `getAnalytics()` | `ControlCenterAnalyticsData` |
| `getMonitoring()` | `ControlCenterMonitoringData` |
| `getRoles()` | `ControlCenterRolesData` |
| `getSettings()` | `ControlCenterSettingsData` |

### Repository implementation

`MockControlCenterRepository` (`lib/core/repositories/mock/mock_control_center_repository.dart`) — platform aggregates with references to Admissions, Finance, SIS, HR, Management, Transport, and Hostel routes.

### Provider wiring

```
Screen → controlCenter*Provider → controlCenterRepositoryProvider → MockControlCenterRepository
```

Registered in `lib/core/repositories/repository_providers.dart` with `useApiRepositoriesProvider` swap to `ApiControlCenterRepository`.
