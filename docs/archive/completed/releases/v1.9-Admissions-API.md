# v1.9 — Live Admissions API Integration

**Release type:** API integration (Admissions module only)  
**Status:** Complete  
**Tests:** 542 passing · Analyzer: 0 issues  
**Baseline:** v1.8 production readiness 68/100 → v1.9 **74/100**

## Summary

Admissions is the **first live API module**. All 11 `AdmissionsRepository` methods are wired through Dio remote calls, DTO parsing, and domain mappers. Other ERP modules remain on mocks.

### Activation

```dart
environmentProvider → enableApiMode: true
admissionsApiEnabledProvider → true
```

All other `*ApiEnabledProvider` flags remain `false` by default.
