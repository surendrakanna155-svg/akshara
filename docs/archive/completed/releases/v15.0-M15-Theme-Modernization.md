## Summary

M15 delivers a premium, AI-native visual layer across Akshara ERP and mobile personas. All changes are confined to design tokens, shared widgets, and dashboard/shell chrome. No workflows, APIs, routes, permissions, or providers were modified.

---

## Delivered

### Design system (`lib/theme/`)

- Centralized M15 token barrel (`m15_design_system.dart` v`15.0.0`)
- Premium academic blue palette with slate/indigo/teal accents
- Obsidian dark theme (layered charcoal surfaces)
- Locale-aware Noto typography (7 languages)
- Motion, glass, accessibility, and page-transition tokens

### Shared widget systems

- Interactive surfaces (press/hover/focus elevation)
- Redesigned KPI cards with trend chips
- Chart card shell, legend, grid, empty state
- Navigation rail, sub-nav tabs, filter chips, search field
- Dialog/bottom-sheet/form chrome
- Glass hero cards (parent/teacher/student)
- Empty/error/loading illustration system
- Fade+scale motion for dialogs and status placeholders

### Surfaces updated

- Mobile dashboards (parent, teacher, student)
- ERP dashboards (management, finance, inventory, intelligence)
- Admin navigation rail, app bar, module sub-navs
- Finance charts and workflow confirm dialogs
- Global search overlay entrance
