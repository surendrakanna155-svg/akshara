# v15.8.2 — Validation Probe UUID Fix

**Tag:** `v15.8.2-validation-probe-fix`  
**Date:** June 2026

---

## Problem

Validation scripts used placeholder `studentId=student_1`, causing:

```
PostgresError: invalid input syntax for type uuid: "student_1"
```

## Fix

- Shared `resolve_probe_student_id()` in `demo_school_lib.py` (parent dashboard → SIS list → staging default UUID)
- Parent experience probes use `PARENT_TOKEN` + real child UUID
- Missing probe student returns **SKIPPED** (not FAIL)

- `demo_school_validate.py`
