# Release v17.4 — Device Auth Validation

**Tag:** `v17.4-device-auth-validation`  
**Date:** June 2026  
**Version:** 17.4.0+174  
**Type:** Validation / QA (no feature code)

---

## Objective

Install v17.3 hardened release builds on connected Android + iPhone devices and validate real authentication against staging API.

---

## Scope

- Build and install release artifacts with `AUTH_API_ENABLED=true`, `ENABLE_API_MODE=true`, `ENABLE_DEMO_AUTH=false`
- API + device smoke for random vs seeded OTP flows
- First-run experience audit (splash, login, onboarding paths)
- Validation report — no backend or UI feature changes

---
