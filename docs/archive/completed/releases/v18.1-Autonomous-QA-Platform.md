# Release v18.1 — Autonomous QA Platform

**Tag:** `v18.1-autonomous-qa-platform`

## Objective

Permanent Maestro-based autonomous QA platform for pre-release regression — journeys, screenshots, reports, one-command runner.

## How to run

```bash
./scripts/qa/setup_maestro.sh
flutter emulators --launch Medium_Phone_API_36.0
BUILD_APK=1 SMOKE_ONLY=1 ./qa/run_all_qa.sh
```

Full regression:

```bash
./qa/run_all_qa.sh
```
