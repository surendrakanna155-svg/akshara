# Release v18.3 — QA Automation Login Mode

**Tag:** `v18.3-qa-login-mode`  
**Date:** June 2026

## Summary

Adds a dedicated **QA Automation Login** screen for Maestro and emulator builds. Persona buttons sign in instantly with no OTP, SMS, or API verification. Production and school release builds are unchanged.

## Enable flags

| Dart define | Effect |
|-------------|--------|
| `QA_AUTOMATION=true` | Enables QA login (non-production only) |
| `ENABLE_QA_LOGIN=true` | Same as above |

Forced **off** when `APP_ENV=production`.

## QA APK build

```bash
./scripts/qa/build_qa_apk.sh
adb install -r build/app/outputs/flutter-apk/app-profile.apk
```

Defines: `ENABLE_QA_LOGIN=true`, `ENABLE_DEMO_AUTH=true`, `ENABLE_API_MODE=false`.

## Maestro

Shared flows now use `qa_persona_login.yaml` (no OTP). Validate all personas:

```bash
maestro test --config qa/maestro/config.yaml qa/journeys/smoke_qa_personas.yaml
```

Typical login step runtime: **~3–5s** per journey (was **~30–45s** with OTP).
