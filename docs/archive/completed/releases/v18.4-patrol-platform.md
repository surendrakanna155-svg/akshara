# Release v18.4 — Patrol Autonomous Testing Platform

**Tag:** `v18.4-patrol-platform`  
**Date:** June 2026

## Summary

Introduces a production-grade **Flutter Patrol** integration layer alongside existing Maestro, `flutter test`, and device QA infrastructure. Patrol provides deep in-app validation: auth lifecycle, dashboards, forms, navigation, performance, and 81+ business journey smokes.
