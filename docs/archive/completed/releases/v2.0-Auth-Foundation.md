# v2.0 — Production Authentication & Backend Foundation

**Release type:** Auth / platform infrastructure (no business API changes)  
**Status:** Complete  
**Tests:** 557 passing · Analyzer: 0 issues  
**Baseline:** v1.9 production readiness 74/100 → v2.0 **79/100**

## Summary

v2.0 delivers production-shaped authentication and platform infrastructure without connecting additional business module APIs. Admissions API implementation is unchanged.

## Staff authentication

### Routes

| Route | Screen |
|-------|--------|
| `/staff/login` | `StaffLoginScreen` |
| `/staff/otp` | `StaffOtpScreen` |

Entry: **Staff ERP portal** button on demo login screen.

### Flow

1. Email or mobile identifier
2. ERP role selection (demo)
3. Remember session toggle
4. OTP send → verify (`654321` or any 6-digit in mock mode)
5. JWT tokens issued → staff session → `/admin` ERP shell

## JWT foundation (`lib/core/auth/`)

| File | Purpose |
|------|---------|
| `jwt_decoder.dart` | Parse JWT payload, expiry checks, mock token builder |
| `token_refresh_service.dart` | Proactive refresh + scheduling |
| `auth_session_manager.dart` | Restore, refresh, expiry logout |
| `auth_providers.dart` | Riverpod wiring + refresh callback |

## Tenant networking

`TenantInterceptor` now sends:

- `X-Tenant-Id`
- `X-School-Id`
- `X-Organization-Id`
- `X-User-Id`

Rejects requests when tenant is required but missing.

## Server RBAC (`lib/core/security/`)

- `server_permission_models.dart` — grants, revocations, policy, cached snapshots
- `server_permission_provider.dart` — local cache (no HTTP sync yet)

## Audit logging (`lib/core/audit/`)

Tracks locally: login, logout, access denied, role change, tenant change.
