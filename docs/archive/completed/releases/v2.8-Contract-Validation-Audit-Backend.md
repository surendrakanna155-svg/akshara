# v2.8 — API Contract Validation & Audit Backend

Release date: 2026-06-07

## Summary

Establishes OpenAPI contract validation for live ERP modules and wires the audit batch upload pipeline to a remote ingestion endpoint. No new business screens or routes.

## OpenAPI Contract Validation

| Component | Path |
|-----------|------|
| OpenAPI spec (v1) | `openapi/akshara-erp-v1.yaml` |
| Schema definitions | `lib/core/network/openapi/openapi_schema.dart` |
| Response validator | `lib/core/network/openapi/openapi_response_validator.dart` |
| Contract registry | `lib/core/network/openapi/openapi_contract_registry.dart` |

### Covered live endpoints

| Module | Path | Schema |
|--------|------|--------|
| Auth | `GET /auth/permissions` | AuthPermissionsEnvelope |
| Auth | `GET /auth/me` | AuthUserEnvelope |
| Admissions | `GET /admissions/dashboard` | DashboardEnvelope |
| Finance | `GET /finance/dashboard` | DashboardEnvelope |
| SIS | `GET /sis/dashboard` | DashboardEnvelope |
| Audit | `POST /audit/events/batch` | AuditBatchUploadRequest / Response |

### Staging gate

Run live staging contract validation:

```bash
flutter test --dart-define=STAGING_CONTRACT_TESTS=true \
  test/integration/auth/permission_sync_openapi_integration_test.dart
```

## Audit Backend Wiring

| Component | Path |
|-----------|------|
| API paths | `lib/core/repositories/api/audit/remote/audit_api_paths.dart` |
| Batch DTOs | `lib/core/repositories/api/audit/dto/audit_batch_upload_dto.dart` |
| Remote datasource | `lib/core/repositories/api/audit/remote/audit_remote_datasource.dart` |
| Uploader providers | `lib/core/repositories/api/audit/audit_upload_providers.dart` |
| Feature flag | `auditApiEnabledProvider` in `repository_config.dart` |

When `enableApiMode` + `auditApiEnabledProvider` are both true, `auditBatchUploaderProvider` drains the upload queue via `POST /audit/events/batch`.
