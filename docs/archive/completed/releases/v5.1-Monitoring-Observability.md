# v5.1 — Monitoring & Observability Foundation

Release date: 2026-06-07

## Summary

Created vendor-agnostic observability architecture with monitoring, analytics, and operational health layers. No vendor SDKs — adapter-ready for Sentry, Datadog, Firebase, New Relic.

## Architecture

```
lib/core/monitoring/     MonitoringService (errors, events, metrics)
lib/core/analytics/      AnalyticsService (product events)
lib/core/observability/  Config, providers, health, bootstrap, metrics registry
```

## Components

| Component | Purpose |
|-----------|---------|
| `MonitoringService` | Error/event/metric recording |
| `AnalyticsService` | Product analytics events |
| `ObservabilityConfig` | Feature flags per environment |
| `ObservabilityHealthSnapshot` | Audit + monitoring health |
| `OperationalMetricsRegistry` | 8 tracked metric descriptors |
| `MonitoringClientAdapter` | Bridges legacy ClientMonitor |

## Feature Flags

- `enableMonitoring` — tied to `Environment.enableLogging`
- `enableAnalytics` — tied to `Environment.enableLogging`
- `enableErrorReporting` — always true (noop until adapter)
