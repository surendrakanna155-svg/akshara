## Architecture Decisions

| Decision | Choice |
|----------|--------|
| Database | PostgreSQL 15+ (Supabase-managed) |
| Initial API layer | PostgREST + Edge Functions |
| Future extraction | NestJS microservices for AI, payments, reports |
| Auth | Phone OTP + JWT RS256 + refresh rotation |
| Tenant boundary | Organization = tenant_id |
| RBAC | 22 permissions aligned with Flutter client |
| Audit | Append-only PostgreSQL + client queue drain |
| Observability | OpenTelemetry → Datadog/Sentry (matches v5.5) |
