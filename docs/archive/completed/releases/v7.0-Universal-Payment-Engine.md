# v7.0 — Universal Payment Engine

**Status:** Complete (stub mode default)  
**Deployment:** Migration + Edge Function env vars

## Summary

Razorpay-backed payment intent lifecycle: initiate → confirm → webhook capture. Tables `payment_requests`, `payment_intents`, `payment_webhook_events`. Parent writes via `POST /parent/payments/initiate|confirm`; ERP routes at `/payments/intents/*` and `POST /webhooks/razorpay`. Invoice linkage creates finance collections on capture. Idempotency via `Idempotency-Key` header + webhook dedupe. Audit events `paymentInitiated`, `paymentCaptured` + domain events.

## API Routes

| Method | Path | Scope |
|--------|------|-------|
| POST | `/parent/payments/initiate` | parent |
| POST | `/parent/payments/confirm` | parent |
| POST | `/payments/intents/initiate` | parent |
| POST | `/payments/intents/confirm` | parent |
| GET | `/payments/intents/:id` | parent, school |
| POST | `/webhooks/razorpay` | webhook (signature) |

## Deployment

```bash
supabase db push   # 20260614600000_universal_payment_engine.sql
supabase functions deploy api
```

**Edge env (live Razorpay):**

```
RAZORPAY_KEY_ID=rzp_live_...
RAZORPAY_KEY_SECRET=...
RAZORPAY_WEBHOOK_SECRET=...
RAZORPAY_STUB_MODE=false
```

**Flutter:** `--dart-define=PARENT_API_ENABLED=true` (parent payment writes); optional `--dart-define=PAYMENT_API_ENABLED=true`.

## Credential Boundary

Without Razorpay secrets, `RAZORPAY_STUB_MODE=true` (default) generates stub orders and accepts stub signatures for dev/staging.
