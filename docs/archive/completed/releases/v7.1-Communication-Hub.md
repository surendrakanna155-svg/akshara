# v7.1 — Communication Hub

**Status:** Complete (stub providers)  
**Deployment:** Migration + Edge Function env vars

## Summary

Notification templates, delivery queue with retry, SMS/Email/Push stub providers, direct messaging threads, school broadcasts, parent/teacher/student notification APIs. Audit + domain events on send/broadcast.

## API Routes

| Method | Path | Scope |
|--------|------|-------|
| GET | `/communications/templates` | school |
| POST | `/communications/broadcasts` | school |
| POST | `/communications/notifications/process-queue` | school |
| GET | `/parent/notifications` | parent |
| GET/POST | `/parent/messages/*` | parent |
| GET/POST | `/teacher/messages` | school (teacher) |
| GET | `/student/notifications` | student |

## Deployment

```bash
supabase db push   # 20260614700000_communication_hub.sql
supabase functions deploy api
```

**Stub providers (default):** `SMS_STUB_MODE=true`, `EMAIL_STUB_MODE=true`, `FCM_STUB_MODE=true`

**Live providers:** `TWILIO_*`, `SENDGRID_*`, `FCM_SERVER_KEY` + set stub modes `false`

**Flutter:** `--dart-define=COMMUNICATION_API_ENABLED=true`
