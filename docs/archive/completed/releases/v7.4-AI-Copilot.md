# v7.4 — AI Copilot

**Status:** Complete

## Scope

Read-only ERP intelligence layer with five module assistants, conversation persistence, role-aware context loading, and audit logging. No autonomous mutations.

## Delivered

| Area | Detail |
|------|--------|
| Backend module | `/copilot/*` routes — assistants, suggestions, sessions, messages |
| Context engine | School, academic year, finance, admissions, SIS, communication, student lookup |
| Prompt orchestration | System prompt builder + OpenAI client (stub when `OPENAI_API_KEY` absent) |
| Persistence | `ai_copilot_sessions`, `ai_copilot_messages` with user-scoped RLS |
| Permissions | `viewAiCopilot`, `runAiCopilot` |
| Flutter repository | `CopilotRepository` — mock + API + hybrid |
| UI | Copilot screen — assistants sidebar, chat, history, suggested prompts |
| Audit | `aiCopilotSessionCreated`, `aiCopilotQuery`, `aiCopilotResponse` |
