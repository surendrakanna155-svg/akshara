**Status:** Complete

## Scope

Academic scheduling engine with generation, validation, clash detection, teacher workload, publish workflow, and read-only AI Copilot scheduling assistance.

## Delivered

| Area | Detail |
|------|--------|
| Timetable engine | Generation, subject/period allocation, teacher/section/room clash detection |
| Workload calculator | Per-teacher period counts with overload threshold |
| APIs | Generate, validate, publish, summary, workload, conflicts |
| Persistence | `academic_timetables`, `academic_timetable_periods` |
| Permissions | `viewAcademicTimetable`, `manageAcademicTimetable`, `publishAcademicTimetable` |
| AI assistance | Academic Copilot context + read-only scheduling recommendations |
| Flutter UI | Timetable hub — dashboard, generate, conflicts, workload, publish tabs |
