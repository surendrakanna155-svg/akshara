# v9.8 — Parent Experience Bridge

**Tag:** `v9.8-parent-experience-bridge`  
**Date:** June 2026

## Summary

Unified parent mobile hub aggregating Student 360 signals, inventory distributions, payment requests, attendance, academics, communication, and parent guidance availability. Parents acknowledge received items or request replacements; acknowledgements update distribution status and emit audit/domain events.

## Backend

| Area | Detail |
|------|--------|
| Table | `parent_item_acknowledgements` — unique per distribution + guardian |
| API | `GET /parent/experience/hub?studentId=` · `POST /parent/experience/acknowledge` |
| Service | `parent_experience_service.ts` — composes Student 360 + inventory lists |
| Replacement | Ack type `replacement_requested` chains to `requestReplacement` |
| Audit | `parent.inventory.acknowledged` via `parentExperienceAudit` |
