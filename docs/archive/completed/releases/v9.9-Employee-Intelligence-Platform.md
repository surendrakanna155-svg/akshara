# v9.9 — Employee Intelligence Platform

**Tag:** `v9.9-employee-intelligence-platform`  
**Date:** June 2026

## Summary

Extends the Employee Platform (v9.6) with workload intelligence snapshots, Employee 360 profiles, and a principal-facing intelligence dashboard. Computes burnout risk, substitution/coordinator load, and balancing recommendations from role assignments and timetable signals.

## Backend

| Area | Detail |
|------|--------|
| Table | `employee_intelligence_snapshots` — workload, burnout, insights JSONB |
| API | `GET /employees/:id/360` · `GET /employees/intelligence/dashboard` |
| Service | `employee_intelligence_service.ts` — 360 profile + dashboard aggregation |
| Fallback | Heuristic workload when no snapshot exists (role-count based) |
| Operations feed | High/critical burnout counts surface in Operations Hub (v10.0) |
