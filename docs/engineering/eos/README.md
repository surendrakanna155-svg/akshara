# EOS Reports

This directory holds the output of the Engineering Operating System skill
(`/eos`, defined in `.claude/skills/eos/`).

- **`EOS_RUN_LEDGER.md`** — one line per run (date · scope · gate verdict ·
  open P0/P1 · report path).
- **`EOS_<SCOPE>_<TYPE>_REPORT.md`** — individual evidence-based reports
  (gap, readiness, certification, roadmap-recommendation, executive summary).

The standard governing all of this is
[../ENGINEERING_GATE_POLICY.md](../ENGINEERING_GATE_POLICY.md), backed by the
[Engineering Constitution](../AKSHARA_ENGINEERING_CONSTITUTION.md). Reports cite
the Constitution by Part + section; they never restate it.
