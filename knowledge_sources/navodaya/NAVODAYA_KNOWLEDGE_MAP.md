# Navodaya (JNVST Class VI) — Knowledge Map

## ముఖ్యమైన నిజం (Important truth)

**Navodaya కోసం separate official textbook series లేదు.**

NVS (navodaya.gov.in) official గా ఇస్తది:

1. **Prospectus** — syllabus + exam pattern + sample question *types*
2. **Answer keys / circulars / OMR sample**
3. Academic content = **Class 5 level NCERT** (Math + Language)

Mental Ability కోసం **official MAT book లేదు**.  
కాబట్టి:
- Concepts → NCERT Symmetry / Patterns (`shared_reasoning/`)
- Practice sets → free community PDFs (clearly labeled, not NVS official)

---

## Exam structure (official)

| Section | Questions | Marks | What to study |
|---------|----------:|------:|---------------|
| Mental Ability | 40 | 50 | Figures: odd one out, matching, completion, series, analogy, geometry completion, mirror, paper folding/holes, space viz, embedded |
| Arithmetic | 20 | 25 | 12 topics (Class 5 NCERT Math) |
| Language | 20 | 25 | Reading comprehension passages |

## Folder map

```
navodaya/
  prospectus/          ← Official syllabus + sample types (2025, 2026)
  previous_papers/     ← Official answer keys
  sample_papers/       ← Official sample OMR
  circulars/           ← Official FAQ / notices
  knowledge_base/
    arithmetic/        ← (optional chapter PDFs; prefer curriculum NCERT ZIPs)
    language/          ← (optional; prefer curriculum NCERT ZIPs)
    mental_ability/
      community_practice/  ← Free MAT chapter PDFs (Veda/Epariksha)
    community_practice/    ← Free NON-official practice pack
      model_papers/        ← Full model papers (Veda, Mendhar)
      mock_tests/          ← Mock tests (Veda)
      previous_papers/     ← Sample / previous-style papers (Mendhar)
      arithmetic_practice/ ← Arithmetic practice sets (Veda)
      language_practice/   ← (add when free PDFs found)
```

Also reuse (no copy):
- `knowledge_sources/shared_reasoning/` — NCERT symmetry / patterns / spatial
- `knowledge_sources/shared_diagrams/` — tangram / cube nets / reflection SVGs
- `curriculum/resources/curriculum/cbse/Class_01..05/` — full NCERT ZIPs already in Akshara
